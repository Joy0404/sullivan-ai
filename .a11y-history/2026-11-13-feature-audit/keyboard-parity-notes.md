# 학생 확장 키보드·도움말 기능 동등성 검사 메모

정적 비교에 의한 기능 차이 분류입니다. WCAG 적합성 점수나 실제 보조공학 사용성 인증이 아닙니다. 검사일: 2026-11-13. 제품과 테스트 코드는 수정하지 않았습니다.

기준 자료는 `apps/web/manual/index.html`, 실행 구현은 `apps/web/role-portal.js`, `focus-voice.js`, `keyboard-navigation.js`입니다. 확장은 `apps/extensions/student/`와 `scripts/build_extensions.py`를 비교했습니다. 설명서와 실행 코드가 다르면 실행 코드와 사용자의 최신 지시를 우선했습니다.

## 사용자 지시로 변경된 동작

Space 1회는 포커스된 버튼 선택이 아니라 강의 재생·정지, 2회는 전체 중지, 3회는 텍스트 명령, 3초 누르기는 음성 명령이라는 최신 계약을 기준으로 삼았습니다. 따라서 원래 설명서의 1회 버튼 선택, 이전 제스처 기본 600ms를 유지하지 않은 것은 누락으로 세지 않았습니다. 확장의 Tab 순환, Escape 해제, F6 안내, 외부 강의 페이지의 키를 가로채지 않는 구성도 승인된 변경으로 취급했습니다.

## 테스트 범위와 제한

이번 작업은 원본·확장 소스와 기존 검증 스크립트를 읽는 검사입니다. 새 브라우저 테스트, 물리 키보드, 실제 Chrome 마이크 권한, 실제 인식 서비스, VoiceOver/NVDA 및 실제 음성 출력을 실행하지 않았습니다. 따라서 현재 오디오가 실제로 겹쳤다는 측정이나 스크린리더 음성을 들었다는 주장은 하지 않습니다.

기존 `scripts/verify_student_repair.py:18-95`는 강의 선택 뒤의 재생 토글·정지·텍스트 전송·3초 임계값(인식기 stub)·권한 취소 경합·Tab/Shift·기본 띄어쓰기·읽기 모드 TTS 억제를 확인합니다. `145-152`는 실제 Chrome side-panel 타깃의 키보드 순환을 확인하도록 구성돼 있습니다. 이 코드를 읽었으며 이번 검사에서 다시 실행하지 않았습니다.

그 스크립트가 확인하지 않는 항목은 첫 가입/첫 로그인 온보딩, 홈에서 음성/타자 강의 선택, 전체 사용법 재호출, 재생 중 focus 안내의 pause/resume, reader focus 일시정지, 설명 중 입력칸의 긴급 중지, Space 직후 Tab/IME/초점 변경, 텍스트 창 취소 후 재생 복원, summary toggle의 음성 상태, 실제 준비 차임입니다. 특히 `verify_student_repair.py:80` 주석은 ‘selected media를 건드리지 않는 app guidance’를 의도하므로 원래 focus pause/resume 기능의 동등성을 입증하는 검증이 아닙니다.

직전 키보드 수리 감사의 빈 findings는 그때 지정된 수리 계약과 소스상 키보드/모달 오류를 검토한 결과입니다. 원래 기능 전체와 동일하다는 의미가 아니며, 이 비교에서는 9개의 기능 차이를 `keyboard.json`의 `wcag: n/a`로 별도 기록했습니다.
