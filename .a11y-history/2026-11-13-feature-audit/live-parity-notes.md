# 학생 음성·명령 기능 원본 대비 감사

기준일: 2026-11-13. 이 문서는 음성·외부 리더·명령 출력의 소스 비교 결과다. 실제 한국어 음질, VoiceOver/NVDA 발화, 사용자 체감을 검증하지 않았다. WCAG 자동 검사와 별개로 원본 기능 보존 여부를 비교했다.

## 원본 UI와 엔진 구분

원본 `apps/web/styles.css:674`는 학생 역할에서 `.player-tools`를 숨긴다. `apps/web/role-portal.js:715`는 읽기 속도·음량·자동 해설만 학생 설정으로 옮긴다. 따라서 따뜻함/차분함/또렷함 선택과 고급 음성 미리듣기를 원래 모든 학생이 직접 조절했다고 표현하면 부정확하다. 다만 원본 학생 낭독에도 warm 기본 프로필, 자연 음성 점수화, 발음 보정, 문장 분할과 호흡은 적용된다. 이 엔진의 차이는 실제로 존재한다.

원본 `apps/web/app.js:1617-1664`의 자동 선택은 한국어를 우선하고 Natural/Neural/Online과 알려진 한국어 음성 이름에 가중치를 준다. 현재 `StudentSpeech`는 정확한 저장 음성만 지정하고 나머지는 브라우저 기본 선택에 맡긴다. `StudentAnnouncer`는 첫 한국어 음성을 쓰므로 안내와 강의 낭독 사이에서도 기본 음성이 달라질 수 있다.

원본 `apps/web/app.js:1667-1805`는 H-R/AI/TTS·숫자/기호를 낭독용으로 바꾸고 문장·쉼표 단위로 분할한다. 말투 프로필과 첫/마지막 문장의 속도·높이를 바꾸고 문장 사이 70/130ms 간격을 둔다. 확장은 이 순수 전처리·프로필 대신 고정 180자 청크를 사용한다. 실제로 더 좋거나 나쁜 소리라는 판단은 소스만으로 하지 않는다.

## 외부 스크린리더의 실제 범위

‘외부 스크린리더 모드’는 VoiceOver/NVDA를 켜거나 감지하는 기능이 아니다. 원본에서도 앱 TTS를 억제하고 접근성 트리·라이브 영역·재생 정지 정책을 제공하는 모드였다. 확장에서 라이브 영역이 존재한다는 사실만으로 원본의 초점 이동 중 일시정지까지 유지됐다고 판단하면 안 된다.

원본 `focus-voice.js:168-173`은 학생 수강 중 리더 모드로 초점을 옮기면 재생을 멈추고 사용자 재생 전까지 기다린다. 확장 `app.js:441-444`는 Announcer만 호출하며, Announcer는 reader 모드에서 즉시 반환하므로 이 재생 보호가 빠져 있다.

## 초기 음성의 플랫폼 경계

초기 Mac 음성은 일반 Chrome 확장만으로 동일하게 자동 실행할 수 있다고 전제하지 않는다. 브라우저 음성의 시작 차단·음성 로딩·출력 장치 등 실제 환경 검증과 명시적 시험 버튼의 접근성을 별도로 확인해야 한다. 원본의 시스템 음성을 그대로 이식하지 못하는 점은 플랫폼 변경 사항으로 명시하고, 확장 첫 방문·새로고침의 실제 동작을 따로 검증해야 한다.

## 복원 우선순위

1. 영상 재생 중 앱 안내와 외부 리더 초점 이동의 정지/복귀 정책을 복원한다. 연결 없는 로그인 안내에는 미디어 소유권을 요구하지 않는다.
2. 학생 홈에도 명령 진입점을 노출하고 강의 선택·사용법은 현재 강의 없이 실행한다.
3. 답변 음성 체크를 초점 음성과 독립시켜 출력 채널을 명확히 한다.
4. 순수 음성 선택·발음·문장/말투 프로필을 공유 모듈로 옮긴다. 음질 개선 판단은 실제 청취 후에만 한다.

## 검증 제안

- 재생 중 연속 Tab: 먼저 정지 확인 → 최신 안내만 발화 → 마지막 안내 후 원래 재생 상태 복귀. 중간 전체 중지·강의 변경·연결 해제 후에는 복귀 금지.
- reader 모드의 재생 중 초점 이동: 일시정지하고 사용자 재생 전까지 정지 유지.
- 로그인 후 첫 강의를 열기 전: Space 길게로 ‘1번 강의 열어줘’, 세 번으로 타자 명령, ‘사용법’ 실행.
- 초점 안내 켠 상태에서 답변 음성만 해제: 일반 타자 질문은 자동 낭독하지 않고 결과는 접근 가능한 경로로 확인.
- 가짜 음성 목록 순서를 바꿔도 Natural/Neural/Online 우선 선택과 사용자 명시 선택 유지.
- 발음 변환·문장 분할·호흡·종결 프로필은 단위검사하고 음질·피로도는 실제 사용자 청취로 검증.
