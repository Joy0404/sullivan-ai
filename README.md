# Sullivan AI — Internet Lecture Accessibility Agent

Sullivan AI는 인터넷 강의에서 **강사가 말하지 않고 화면으로만 전달한 정보**를 찾아 설명하고, 강사가 강조한 핵심 개념과 흐름을 시각장애 학생이 음성으로 탐색하도록 돕는 SDG 4 기반 학습 접근성 에이전트입니다.

> 현재 상태: 대회용 통합 MVP 1.4
> 실제 동작: 로컬 영상 및 공개 링크 재생, 별도 동의한 업로드 영상의 실제 Gemini 발화·화면/OCR 분석, Gemini 장면 분석→독립 시각 근거 재검증, 음성-화면 비교, 모델 기반 개입 시점 선택, Pause→TTS→Resume, 강사 구간→AI 재설명 핵심 탐색, 긴 지문 문단 흐름·밑줄 문단 재청취, Space 2초 전역 음성 명령, Space 세 번 텍스트 명령, 자유 키보드 조작 모드, 로컬 강의 보관함, 접근성 복습, 음성 학습 대화, 개인정보 비공개 처리, 안전 보류.
> 연결 필요: `GEMINI_API_KEY`를 설정하면 공개 YouTube와 별도 전송 동의한 로컬 영상의 음성·화면 분석, 학습 대화의 에이전트 행동 선택을 실제 Gemini가 수행합니다. 그 밖의 영상 링크는 `LINK_ANALYZER_URL`에 별도 멀티모달 분석기를 연결할 수 있습니다. 샘플 모드는 이 경계를 재현 가능한 데이터로 시연하며 실제 분석인 것처럼 표시하지 않습니다.

## 왜 필요한가

인터넷 강의는 음성만으로 구성되지 않습니다. 강사가 식의 부호를 바꾸고, 긴 지문의 한 문장에 밑줄을 긋고, 그래프의 축을 가리키면서 “여기가 중요합니다”라고 말할 때 핵심 정보는 화면에만 남습니다. 일반 TTS는 화면 전체를 읽고, 일반 요약 AI는 강의가 끝난 뒤 내용을 압축하지만, 학생이 지금 놓친 시각정보와 원하는 문장 위치를 즉시 되찾게 하지는 못합니다.

Sullivan AI의 핵심은 OCR이나 TTS 자체가 아니라 다음의 연결입니다.

```text
관찰 → 화면 유형 선택 → 강사 발화와 비교 → Visual Gap 판정
    → Gemini가 개입 행동 제안 → 안전 계층 검증
    → 필요한 경우 영상 정지·음성 해설 → 판서·지문 상태 갱신
```

학습 대화도 단순한 문답 창이 아니라 아래 에이전트 루프를 사용합니다.

```text
현재 강의·재생 위치 관찰 → Gemini가 다음 행동 선택
    → 설리번이 개인정보·근거·문제 보호 정책 재검증
    → 답변 / 요약 낭독 / 구간 이동 / 화면 해설 / 문단 재청취 / 정지 실행
    → 결과와 판단 근거 표시 → 저장된 강의와 요약을 로컬 기억으로 재사용
```

Gemini 같은 기반 모델 자체를 처음부터 새로 학습한 프로젝트는 아닙니다. 기반 모델 API에 Sullivan AI가 만든 관찰 구조, 행동 도구, 안전 정책, 재생 제어, 로컬 기억을 결합한 **도구 사용형 에이전트 시스템**입니다. 대회에서 말하는 에이전트성은 모델 소유 여부가 아니라 목표를 위해 상태를 관찰하고 다음 행동을 선택·실행하며 결과를 기억하는 흐름에서 나옵니다.

## SDG 4 — Learning Parity

SDG 4의 목표는 포용적이고 형평성 있는 양질의 교육입니다. Sullivan AI는 다른 학생이 눈으로 얻는 정보와 탐색 행동에 접근할 수 있게 하되, 문제의 정답을 대신 제공하지 않습니다. **장벽은 제거하고 학습 과정은 보존하는 것**이 Sullivan AI의 형평성 원칙입니다.

- 문제 모드에서는 `answer` 관측을 화면과 TTS 모두에서 차단합니다.
- 확신도 72% 미만의 OCR 후보는 내용 자체를 공개하지 않습니다.
- 강사가 이미 충분히 말한 화면정보는 복습 인덱스에만 남겨 불필요한 개입을 줄입니다.
- 원본 영상은 기본적으로 `URL.createObjectURL`로 브라우저에서만 재생합니다. 사용자가 실제 AI 분석에 별도 동의했을 때만 Gemini에 임시 전송하고 분석 직후 로컬·공급자 파일 삭제를 요청합니다. `강의 저장`을 직접 선택한 경우에만 같은 브라우저의 IndexedDB에 보관합니다.

## 구현된 사용자 흐름

1. 이용 권한이 있는 MP4/WebM 파일 또는 YouTube·공개 영상 링크와 TXT/MD/SRT/VTT/분석 JSON을 선택합니다.
2. 영상은 브라우저 로컬에서 재생됩니다. 실제 AI 분석을 별도로 체크하면 같은 영상에서 시간대별 실제 발화, 보이는 글자·판서·슬라이드를 추출하고 2차 시각 검증을 거쳐 세션에 색인합니다. 체크하지 않으면 원본은 전송되지 않습니다.
3. 에이전트가 강사 발화와 화면 관측을 비교해 `INTERRUPT`, `DESCRIBE_AT_BREAK`, `INDEX_ONLY`, `HOLD`, `SKIP` 중 하나를 선택합니다.
4. 중요한 미발화 수식·숫자·조건은 영상을 멈추고 자연스러운 한국어 TTS로 설명한 뒤 재생합니다.
5. 강사가 중요하게 설명한 키워드·인물·원인·전개·결과·비교·정책 흐름을 찾고, `말하기`를 누르면 해당 강사 구간 뒤에 AI 재설명을 듣습니다.
6. 긴 지문의 문단별 역할과 전체 흐름을 확인하고, 필요한 문단에 밑줄을 표시한 뒤 `밑줄 친 문단 다시 들려줘`, `2문단`, `앞 문단`, `다음 문단`처럼 음성 또는 텍스트로 재청취합니다.
7. 주제별 요약·개념 비교·시간순 흐름·원인/전개/결과·암기표·복습 계획·퀴즈·발표문을 음성 또는 텍스트로 요청합니다. Gemini 행동 에이전트가 답변, 요약 낭독, 구간 이동, 화면 해설, 문단 재청취, 정지 중 하나를 고르고 설리번 안전 계층이 실행합니다. 키가 없으면 기존 로컬 보조 대화로 자동 전환합니다.
8. 강의 후 타임스탬프가 연결된 Accessible Lesson Review를 제공합니다.
9. 강의가 끝나거나 학습 중 `강의 저장하고 홈으로`를 누르면, 로컬 영상은 원본 Blob과 분석·요약을 브라우저 IndexedDB에 저장합니다. YouTube는 영상 파일 대신 원본 링크와 분석·요약만 저장합니다.
10. 홈의 `내 강의 보관함`에서 버튼 또는 `최근 강의 다시 열어줘`, `별의 진화 요약 들려줘` 같은 음성·텍스트 요청으로 다시 학습합니다.

## 영상 링크 및 업로드 분석

- 로컬 MP4/WebM/MOV/M4V는 기본적으로 브라우저에서만 재생합니다.
- 첫 화면에서 `선택한 영상의 실제 발화·판서·슬라이드를 Gemini로 임시 분석`을 체크한 경우에만 원본을 전송합니다. API는 임시 파일을 분석 완료 또는 실패 즉시 지우고 Gemini Files API 파일도 삭제 요청합니다. 원격 삭제 요청이 실패하면 공급자 정책상 최대 48시간 뒤 자동 삭제될 수 있습니다.
- 공개 MP4·WebM 링크는 HTML 영상 플레이어에서 직접 재생합니다.
- YouTube 링크는 개인정보 보호 강화 임베드 주소로 변환해 재생합니다.
- 그 밖의 링크는 소스로 등록하되 내장 재생 가능하다고 가정하지 않습니다.
- API는 링크를 직접 다운로드하거나 DRM을 우회하지 않습니다.
- 공개 YouTube 링크와 별도 동의한 로컬 영상은 `.env` 또는 첫 화면에 `GEMINI_API_KEY`가 있으면 Gemini 영상 이해 기능으로 음성·화면을 직접 분석합니다. 1차 에이전트가 실제 발화와 장면·개입 시점을 찾고, 2차 독립 시각 근거 에이전트가 같은 영상을 다시 보며 각 관측을 확인·수정·삭제합니다.
- 같은 키로 AI 학습 대화의 행동 계획도 생성합니다. 대회 시연 PC에서는 첫 화면의 `Gemini API 키` 칸에 키를 입력할 수 있고, 키는 현재 브라우저 메모리에만 두며 세션·응답·강의 보관함에 저장하지 않습니다.
- 링크 분석이 완료되기 전에는 영상 화면으로 넘어가지 않으며, 완료 후 실제 YouTube 재생시간에 맞춰 화면 해설과 요약 음성 가이드가 활성화됩니다.
- 그 밖의 링크는 `.env`의 `LINK_ANALYZER_URL`에 연결된 임시 분석 서비스가 수행합니다. 서비스는 분석 후 원본을 삭제하고 [분석 패키지 계약](docs/ANALYSIS_PACKAGE.md)을 반환해야 합니다.

```powershell
Copy-Item .env.example .env
notepad .env
docker compose up --build
```

`.env` 예시:

```dotenv
GEMINI_API_KEY=Google_AI_Studio에서_발급한_키
GEMINI_MODEL=gemini-2.5-flash
GEMINI_AGENT_MODEL=gemini-2.5-flash

# 공개 MP4 등 YouTube 이외 링크 분석용(선택)
LINK_ANALYZER_URL=https://your-authorized-analyzer.example/v1/analyze
LINK_ANALYZER_TOKEN=your-token
```

API 키나 어댑터가 설정되지 않은 경우 링크 재생만 준비되고 화면에는 `분석 어댑터 필요`가 명확히 표시됩니다. 이 상태를 AI 분석 완료로 표시하지 않습니다. 공개 YouTube URL 직접 분석은 Gemini API의 프리뷰 기능이므로 모델명과 사용량 정책이 바뀔 수 있습니다.

### 어떤 AI API를 사용하는가

- 새 공개 YouTube와 별도 동의한 로컬 영상의 음성·화면 분석에 Google Gemini API를 사용합니다. 로컬 영상은 Files API에 임시 업로드하고, `GEMINI_MODEL`이 전체 영상을 자율적으로 훑어 실제 발화와 장면 후보를 고른 뒤 같은 모델의 별도 검증 호출이 장면 전후와 실제 판서를 다시 대조합니다. 화면 근거 목록과 `confirmed` 또는 `corrected` 판정이 없는 관측은 확신도가 높아도 TTS에 들어가지 않습니다. Interactions API를 사용할 수 없는 계정에서는 `GEMINI_FALLBACK_MODEL`의 `generateContent` 형식으로 동일한 2단계 검증을 수행합니다.
- AI 학습 대화에서는 `GEMINI_AGENT_MODEL`이 현재 강의와 재생 위치를 관찰하고 `answer`, `read_summary`, `seek`, `describe_current`, `replay_paragraph`, `pause` 중 행동 하나를 선택합니다. 화면에는 선택 행동과 짧은 판단 근거가 함께 표시됩니다.
- Gemini는 실제 프레임과 앞뒤 발화를 바탕으로 `즉시 정지`, `자연스러운 틈에 설명`, `복습에만 저장`, `보류`, `생략` 중 행동을 제안합니다. 설리번의 결정·안전 계층은 낮은 확신도, 개인정보, 문제 보호, 발화 중복과 허용된 플레이어 동작을 다시 검사합니다. 모델이 임의 코드를 실행하거나 허용되지 않은 도구를 호출할 수 없습니다.
- TTS와 음성 입력은 브라우저의 Web Speech API를 사용합니다. 별도 OpenAI·Claude API를 호출하지 않습니다.
- Gemini 키가 없어도 검증된 두 샘플, 저장된 강의, 자동 정지, 문단 재청취와 제한적 로컬 보조 대화는 작동합니다. 새 영상의 유동적인 장면 이해와 에이전트 행동 판단에는 키가 필요합니다.
- 화면에서 입력한 Gemini 키는 영상 분석과 에이전트 요청 본문에서만 사용하고 세션·응답·강의 보관함에 저장하지 않습니다. 서버 `.env`에 키가 있으면 홈 입력란은 숨겨집니다.

## 내 강의 보관함

- 로컬 영상: 사용자가 저장을 선택했을 때만 원본 파일, 분석 결과, 요약, 마지막 재생 위치를 브라우저 IndexedDB에 저장합니다.
- YouTube·공개 링크: 저작권 보호를 위해 영상 파일을 내려받지 않고 URL, 분석 결과, 요약, 마지막 재생 위치만 저장합니다.
- 저장 데이터는 서버나 클라우드로 보내지지 않으며 같은 노트북·브라우저에서만 다시 열 수 있습니다.
- 브라우저 사이트 데이터를 삭제하면 보관함도 삭제됩니다. 큰 로컬 영상은 브라우저 저장 용량을 초과할 수 있으며, 이 경우 용량 부족 안내를 표시합니다.

## 3분 실행

Docker Desktop이 있다면 저장소 루트에서 실행합니다.

```bash
docker compose up
```

- 웹: <http://localhost:8000> (API가 웹 화면도 함께 제공합니다)
- API 문서: <http://localhost:8000/docs>
- 공개 배포: [DEPLOY_RENDER.md](DEPLOY_RENDER.md) (Render), [DEPLOY_RAILWAY.md](DEPLOY_RAILWAY.md) (Railway)

첫 화면의 `샘플 영상 보기`에서 다음 두 영상을 선택할 수 있습니다.

- 샘플 1 · 과학: [별의 진화](https://www.youtube.com/watch?v=R0dqsl3Vgns)
- 샘플 2 · 역사: [왜란과 호란의 발발과 영향](https://www.youtube.com/watch?v=thJxqtTgSNY)

두 샘플 모두 사전에 준비된 접근성 결과를 분석 대기 없이 엽니다. 샘플 데이터는 웹에 포함되어 API 서버가 일시적으로 연결되지 않아도 해설·요약·학습 노트를 이용할 수 있으며, 현재 실행에서 영상을 새로 분석한 것처럼 표시하지 않습니다.

## 학습 접근성 기능

- 실제 링크 분석 또는 로컬 자료 준비 중에는 회전 애니메이션과 예상 진행률(%)을 함께 표시합니다.
- 자동 해설 시점과 `현재 화면 해설` 요청 모두 `재생 정지 → TTS 해설 → 자동 재생` 흐름으로 동작합니다.
- 재생시간이 해설 시점을 통과했는지 추적하므로 버퍼링이나 짧은 탭 지연으로 정확한 순간을 놓쳐도 안전한 시간 범위 안에서 자동 개입합니다. 샘플의 첫 자동 개입은 0분 43초입니다.
- 사용 가능한 한국어 음성 중 Natural·Neural·Online 음성을 우선 선택하고, 음색(설치 음성)·말투·음높이·음량·속도와 문장 단위 호흡·고유명사 발음 보정을 제공합니다. 실제 음색 품질의 상한은 노트북과 브라우저에 설치된 한국어 음성 엔진에 따라 달라집니다.
- 과학 샘플은 10개 자동 해설 구간과 19개 핵심 개념, 역사 샘플은 12개 자동 해설 구간과 35개 핵심 개념을 제공합니다.
- 자동 화면 해설은 `현재 강의 맥락 1문장 → 화면 핵심 → 다음 내용과의 연결 1문장`으로 구성합니다. 앞뒤 문장은 각각 42자 이하로 제한해 맥락은 살리되 강의보다 길게 말하지 않습니다.
- TTS는 시작 문장을 조금 천천히, 마지막 연결 문장은 음높이와 속도를 아주 조금 낮추고 문장 사이에 짧은 호흡을 둡니다. `음성 미리 듣기`로 현재 선택한 음색·말투·음높이·음량·속도를 확인할 수 있습니다.
- `핵심 탐색`의 말하기는 해당 개념의 강사 설명 구간을 최대 22초 재생하고 영상을 멈춘 뒤 AI가 다시 설명합니다. `강사·AI 재생 멈춤`, `영상·음성 멈춤`, `Esc`는 영상과 TTS를 함께 즉시 중지합니다.
- `긴 지문 흐름·문단 다시 듣기`는 문단 역할을 순서대로 제시하고, 여러 문단의 밑줄 상태를 유지합니다. 문단 재청취가 시작되면 재생 중인 영상을 자동으로 멈추며 낭독이 끝난 뒤 이어서 재생합니다.
- 문단 탐색은 `전체 흐름`, `2문단`, `앞 문단`, `다음 문단`, `밑줄 친 문단 다시 들려줘` 명령을 지원하고, 각 문장 버튼은 문단·문장 번호와 강조 여부를 스크린리더 이름에 포함합니다.
- AI 학습 노트에서 한눈에 요약, 개념 연결 지도, 핵심 용어, 정답을 노출하지 않는 회상 질문을 제공합니다.
- 요약과 AI 학습 대화 결과는 기본적으로 TTS로 읽으며, 재생 중이면 영상을 잠시 멈춘 뒤 음성이 끝나면 이어서 재생합니다.
- Web Speech API를 지원하는 브라우저에서는 어느 화면에서든 `Space`를 2초 이상 누르면 첫 띠링 뒤 사용 가능한 명령을 음성으로 안내합니다. 첫 Space를 떼어도 안내는 끝까지 이어집니다. 안내 도중 Space를 다시 0.65초 이상 누르면 남은 명령 목록을 즉시 생략하고 마이크가 켜지며, 누르는 동안 말한 뒤 키를 떼면 샘플 선택, 영상 시작·정지, 화면 해설, 요약 낭독, 핵심·문단 탐색, 메뉴·버튼 선택, 저장 강의 요청과 홈 이동을 실행합니다. 안내를 끝까지 들은 경우 다음 길게 누르기는 목록을 반복하지 않고 바로 음성 인식을 시작합니다.
- 음성 인식이 무음 때문에 잠깐 종료되면 Space를 누르는 동안 자동으로 다시 연결합니다. 최초 마이크 권한 창이 떠서 화면 포커스가 잠시 바뀌어도 명령 세션을 취소하지 않으며, 차단·마이크 없음·연결 문제를 서로 다른 문장으로 안내합니다.
- `Space`를 빠르게 세 번 누르면 별도 클릭 없이 포커스된 텍스트 명령창이 열립니다. 바로 타이핑한 뒤 Enter를 누르면 음성 명령과 같은 라우터로 실행하며, 입력창 안의 Space는 정상적인 공백으로 처리합니다.
- 음성 또는 텍스트로 `자유 모드`, `수동 모드`, `키보드 모드`라고 명령하면 마우스 클릭과 화면의 모든 버튼을 제한 없이 직접 사용할 수 있고, Space 한 번으로 재생·일시정지, 좌우 화살표로 10초 이동, 기존 단축키도 사용할 수 있습니다. 자유 모드에서 Space를 빠르게 두 번 누르면 에이전트 명령 모드로 돌아옵니다. 일반 에이전트 화면에서도 좌우 화살표와 `Alt+←/→` 이동은 유지됩니다.
- 일반 모드에서 `Space`를 빠르게 두 번 누르면 현재 TTS·명령 안내·음성 인식을 중지하고 강의를 재생합니다. 세 번 입력과 구분하기 위해 두 번째 입력 뒤 최대 0.65초 동안 세 번째 입력을 기다립니다. YouTube 플레이어의 기본 Space 단축키는 비활성화하고 iframe 초점을 상위 앱으로 되돌립니다.
- 음성으로 요청한 자유 형식 결과물은 현재 강의 근거에 따라 화면에 표시되고 자동으로 낭독됩니다.
- 문제 보호 모드를 켠 세션에서만 최종 정답을 보류합니다. 기본 일반 학습 모드에서는 검증된 전체 화면 설명과 정답 정보를 가리지 않습니다.
- 전화번호·이메일·주민등록번호 형태는 공개 출력과 TTS 전에 비공개 문자열로 바꿉니다.
- 학생이 현재 재생 위치에 메모를 남기고 전체 학습 노트를 Markdown 파일로 저장할 수 있습니다.
- `Alt+D` 화면 해설, `Alt+S` 요약, `Alt+B` 북마크, `Alt+←/→` 10초 이동, `Esc` 영상·음성 중지 단축키를 지원합니다.

Windows에서 직접 실행하는 방법은 [START_HERE.md](START_HERE.md)를 참고하세요.

- Docker Desktop 실행 후 `RUN_WINDOWS.bat`을 더블클릭하면 웹과 API를 백그라운드에서 시작하고 브라우저를 엽니다.
- 종료할 때는 `STOP_WINDOWS.bat`을 사용합니다.
- 설치, WSL 2, 포트 충돌, 마이크 권한, Docker 없이 실행하는 방법까지 `START_HERE.md`에 순서대로 포함되어 있습니다.
