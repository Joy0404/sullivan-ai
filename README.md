# Sullivan AI 학생·보호자 로컬 작업본

시각장애 학생의 수강과 보호자의 강의 준비·배정을 분리한 앱입니다. `Develop` 브랜치에 로컬 작업본의 실행 코드와 회귀 검사를 통합했습니다.

## 시작

```bash
bash START_LOCAL.command --sample
```

http://127.0.0.1:8770 에 접속합니다. 최초 접속자는 보호자 계정을 직접 만들고, 학생 계정을 연결합니다. 테스트 계정은 미리 넣지 않았습니다.

보호자: 학생 생성 → 샘플 또는 자료 준비 → 학생 배정·준비 완료 → 로그아웃.
학생: 연결된 계정으로 로그인 → 최초 안내 확인 → 강의 목록에서 선택.

실제 Gemini 분석이 필요하면 `bash START_LOCAL.command`로 실행해 기존 실행기의 숨김 입력을 사용합니다. 모델·공급자 호출 설정은 원본 그대로입니다. API 키는 브라우저에 입력하지 않습니다.

## 사용법

- 학생 기본 목적: 강의 듣기, 지문·문단 듣기, 원하는 내용 찾기, 질문하기.
- 로그인 화면은 ‘학생 로그인’에 초점을 두고 이름을 안내합니다. 로컬 Mac 실행기는 첫 안내를 시스템 한국어 음성으로 재생해 새로고침 후에도 별도 조작 없이 시작합니다. 그 밖의 실행에서는 브라우저 음성을 사용하며, 자동 음성이 차단되면 ‘로그인 음성 시작·시험’을 누르세요.
- Tab은 다음, Shift만 눌렀다 떼면 이전입니다. Shift+Tab도 사용할 수 있고 입력칸의 Shift는 원래 입력·선택 기능을 유지합니다.
- 강의를 열면 ‘강의 재생’에서 시작합니다. 재생 → 영상·해설 모두 중지 → 현재 화면 다시 설명 순서입니다. 왼쪽·오른쪽 방향키로 10초 이동하며 입력 중에는 글자 이동을 유지합니다.
- 앱의 버튼 음성 안내 중에는 강의가 잠시 멈췄다가 이어집니다. 영상 내부 조작 버튼들은 탐색에서 건너뜁니다. 외부 스크린리더 모드에서는 재생 버튼으로 직접 이어 듣습니다.
- 그 영역에서 Space 길게: 누르며 말하고 떼기. 두 번: 영상·음성 중지. 세 번: 타자 명령.
- 입력창 Space는 띄어쓰기, Enter는 전송, Esc는 취소입니다. 마이크를 쓸 수 없으면 타자 창을 제공합니다.
- 위치·밑줄·북마크·메모는 계정별로 서버에 자동 저장합니다. 복습·학습 노트는 학습 기록에서 엽니다.
- 학생은 읽기 속도·음량·자동 해설을 직접 조절할 수 있습니다. 기본값과 문제 보호 정책은 보호자가 설정합니다.
- 명시적으로 저장한 로컬 영상은 브라우저에 AES-GCM으로 암호화합니다. 서버는 원본을 보관하지 않습니다. 해당 원본은 같은 브라우저·같은 주소에서만 열 수 있습니다. 링크 강의는 원본 링크만 사용합니다.
