# 학생·보호자 독립 확장 개발 버전

두 개의 별도 MV3 패키지와 독립 로그인 세션을 제공한다. 0.4는 [개발 계획](../../docs/EXTENSION_DEVELOPMENT_PLAN.md)의 계정 분리·연결·운영 기반까지 구현한 개발 버전이다. 실제 강의 사이트·음성 인식·스크린리더 검증은 진행 전이며 스토어 출시 버전이 아니다. 기존 웹 기능도 유지된다.

최신 로컬 버전은 **0.4.9**이다. 판서의 수식·숫자 차이를 먼저 비교하고 불확실한 부분만 지정 문구로 보류한다. 분석 상태는 실제 서버 처리 기록과 사전 준비 샘플을 구분한다. [제출본 설치 안내](../../docs/SUBMISSION_INSTALL.md)와 [수정·검증 보고](../../docs/EXTENSION_SUBMISSION_REPORT.md)를 참고한다. 학생이 처음 한 번 로그인하고 연결 코드·기기 지원을 승인하면 보호자가 학생 이름을 골라 학생 기기에 원격 로그인을 시작할 수 있다. [보호자 로그인 지원 설정·사용·검증](../../docs/EXTENSION_REMOTE_LOGIN.md)을 참고한다. API 서버와 두 확장을 업데이트하고 열린 확장 화면을 다시 열어 적용한다. 0.4.7의 일반 링크·로컬 파일 연결과 0.4.6의 인증·저장 경합 수정도 포함한다.

## 학생 최소 필기 변경 (2026-11-16)

현재 소스는 네 작업을 분리한다. 강의 목록에서 강의를 연 뒤 **강의 듣기 → 필기 → 내용 찾기 → 설정·관리**로 이동한다. 다른 작업의 본문과 조작은 현재 Tab 순서에 들어오지 않는다. 타자 명령은 한 개의 창으로 통합했고, 기존 Space·Shift·Esc·F6와 마이크 동의는 유지한다.

필기에서 제목 없이 바로 작성하고 자동 저장한다. 문장·식을 직접 선택해 연결하거나 자유 필기를 쓴다. 연결 원문 확인을 닫으면 편집 커서로 돌아온다. 실패한 초안은 같은 기기의 같은 학생 계정에 남으며, 지금 저장·재시도로 복구한다. 다른 화면의 변경과 충돌하면 초안을 새 필기로 보존한다. 기존 한 칸 메모는 복사 버튼으로 옮길 수 있으며 원본은 삭제하지 않는다. 설정·관리의 보관된 내 필기에서 배정 종료 뒤에도 자기 필기를 수정·내보낼 수 있다.

학생용 발표문·암기표·복습 계획·11종 추가 도구 선택과 학습 가이드 전체 듣기 진입은 제거했다. 짧은 요약·원문·핵심 개념·복습 내용·강의 근거 질문과 기존 웹 기능은 유지한다. 학생이 작성한 본문은 자동 교정하거나 AI 공급자에게 일괄 전송하지 않는다. 원문은 현재 공개 가능 여부를 다시 검사해 조회·내보낸다.

[구현·검증·복원 보고](../../docs/EXTENSION_STUDENT_NOTES.md)를 참고한다. 새 API를 쓰므로 서버에 현재 코드를 적용하고 확장을 다시 빌드·다시 로드해야 한다. 이번 작업은 사용 중인 서비스를 종료하거나 운영에 배포하지 않았다. 기존 아래 버전 이력과 누적 브라우저 스크립트는 당시 UI 기준이며, 현재 흐름 검사는 `scripts/verify_student_notes.py`이다.

## 로컬 실행

프로젝트 루트에서 기존 서버를 실행한다.

```bash
bash START_LOCAL.command --sample
```

다른 터미널에서 패키지를 생성한다.

```bash
python3 scripts/build_extensions.py
```

Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 ‘압축해제된 확장 프로그램을 로드합니다’로 다음 두 폴더를 각각 선택한다.

- `dist/extensions/guardian`: 보호자 아이콘을 누르면 전용 관리 탭이 열린다.
- `dist/extensions/student`: 학생 아이콘을 누르면 전용 사이드 패널이 열린다.

보호자 프로그램은 처음 접속할 때 **보호자 사용 설명서 → 확인하고 시작하기 → 로그인·회원가입 선택** 순서로 열린다. 두 작업 중 하나를 선택해야 해당 화면이 나타난다. 다음 접속부터는 로그인·회원가입 버튼을 먼저 보여 주며, 위의 ‘보호자 설명서’로 필요할 때 안내를 다시 볼 수 있다. 유효한 로그인 상태가 남아 있어도 선택 화면을 먼저 보여 주고, ‘로그인’을 누르면 작업 화면으로 이어진다. 설명서 확인 여부는 해당 확장의 Chrome 프로필에만 저장하며 학생 프로그램에는 적용하지 않는다.

기존 학생·보호자 계정으로 각 프로그램에 로그인한다. 새 로컬 개발 환경에서는 보호자 설명서 확인 → 회원가입 → 복구 코드 보관 → 로그인 → 학생 계정 생성 → 샘플 배정 → 학생 확장 로그인 → 목록 새로고침 → 자료 열기 → 메모 저장을 진행한다. 로컬 시험 계정은 회원가입 화면의 ‘로컬 개발 계정 만들기’로도 만들 수 있다. 한쪽 로그아웃이 다른 프로그램의 로그인에 영향을 주지 않아야 한다.

브라우저 로그인은 PKCE 인증과 갱신 자격 회전을 사용한다. 기본적으로 세션 저장소만 사용하며, 명시적으로 ‘내 기기 로그인 유지’를 선택하면 갱신 자격을 확장 전용 로컬 저장소에 보관해 재시작 뒤 복구한다. 사용 중 로그아웃은 서버의 해당 로그인 계열과 기기의 기억도 폐기한다. 서버 연결 실패 시 로그아웃 오류를 표시하고 재시도할 수 있게 세션을 유지한다.

## 보호자 준비와 관리

‘새 강의 준비’에서 자막·지문·표준 분석 JSON, 링크와 보조자료, 원본 파일 실제 분석을 선택한다. 자막·지문은 실제로 처리하고, JSON은 기존 표준 분석 계약으로 검증한다. 링크 분석을 선택하지 않으면 보조자료가 있어야 한다. 실제 분석에는 영상 이용 권한·전송 동의·기존 서버의 분석 연결과 이용 제한이 적용된다.

파일의 실제 분석은 `--sample`이 아닌 기존 실제 분석 실행 방식으로 서버를 시작하고 서버에 공급자 연결을 설정해야 한다. API 키를 확장에 입력하거나 패키지에 넣지 않는다. 원본 파일 분석은 학생에게 영상을 전송하는 기능이 아니다.

준비 상태를 확인한 뒤 ‘결과 확인·배정’에서 학생을 선택한다. 강의 목록에서는 제목·과목·배정 수정, 확인 후 전체 회수, 비공개 자료 재공개를 제공한다. 학생 현황에서는 기본 설정·진도 요약·배정 순서를 관리한다. 회수해도 학생 개인 기록은 삭제하지 않는다.

준비 결과는 DB에 남고 탭을 닫아도 접수한 처리는 서버에서 계속된다. 서버 재시작으로 중단된 작업은 자동 재시도하지 않는다. 다시 준비 버튼에서 자료와 동의를 재선택한다. 현재는 서버 프로세스 하나로 실행해야 하며 다중 워커는 지원하지 않는다.

코드 갱신 뒤에는 기존 로컬 서버를 재시작하고 빌드를 다시 실행한 후 `chrome://extensions`에서 두 확장을 새로고침한다. 서버가 이전 코드로 실행 중이면 새 준비 API를 사용할 수 없다.

## 서버 주소와 운영 경계

기본 서버는 `http://127.0.0.1:8770`이다. 다른 로컬 포트 또는 향후 HTTPS 서버는 빌드 시 지정한다.

```bash
python3 scripts/build_extensions.py --server https://your-sullivan-server.example
```

운영 서버는 `SULLIVAN_PRODUCTION=1`과 `SULLIVAN_EXTENSION_CLIENTS`에 학생·보호자 확장 ID를 각각 등록해야 한다. HTTPS 출처·영속 디스크·단일 프로세스 검사를 통과해야 시작된다. 관리자·초대 코드를 입력하지 않고 독립 가입한다. 운영자가 신규 가입을 잠시 막으려면 서버의 SULLIVAN_SIGNUP_ENABLED를 0으로 설정한다. 운영에서는 각 역할이 독립 가입하고 보호자의 일회용 코드를 학생이 확인·승인해 연결한다. 복구 코드·로그인 기기 종료·연결 해제도 각 확장에서 제공한다. 자세한 설정과 데이터 이전·원복·스토어 제출 조건은 [운영 안내](../../docs/EXTENSION_OPERATIONS.md)를 따른다. 로컬 개발 서버는 루프백에 바인딩하며 인터넷에 노출하지 않는다.

패키지에 API 키·계정 DB·세션·학생 기록을 포함하지 않는다. 코드·화면의 공통 부분만 공유하고, 상대 역할의 화면·스크립트는 복사하지 않는다. 학생 원본 탭 연결 시 해당 출처의 선택 권한을 요청하며, 모든 사이트를 설치 때 허용하지 않는다. 음성 인식은 별도 동의와 브라우저 허용이 필요하고 화면·오디오 캡처 권한은 요청하지 않는다.

## 학생 수강

강의를 고른 뒤 ‘원본 강의 열고 연결’을 누르거나, 원본 강의 탭 옆의 사이드 패널에서 ‘현재 강의 탭 연결’을 누른다. 선택한 사이트와 필요한 영상 제공자 출처 권한을 허용한 뒤 ‘강의 재생’으로 시작한다. 일반 HTTP(S) 페이지·SPA, 허용된 iframe·열린 Shadow DOM의 표준 HTML 영상도 탐색한다. 모든 상용·보호된 플레이어의 호환을 의미하지 않는다. [0.4.7 사용·검증 범위](../../docs/EXTENSION_CHROME_PLAYBACK.md)를 참고한다.

보호자는 링크만 등록하거나 ‘로컬 파일 재생용 등록’으로 이름·크기만 등록해 배정할 수 있다. 학생은 ‘내 기기의 영상 연결·보관’에서 원본을 선택한다. 원본을 서버로 업로드하지 않는다. 실제 파일 분석 때 저장한 SHA-256·크기와 일치하면 시점 해설과 준비된 자막을 연결한다. 식별 정보가 없으면 수동 재생·자료 읽기를 사용한다. Chrome에서 실제 디코딩 가능한 파일이 필요하며 재생 등록을 영상 분석이라고 표시하지 않는다.

암호화 보관은 체크한 경우에만 동작하고 100MB 이하를 지원한다. 보관 원본은 동일 Chrome 프로필의 같은 학생 계정·배정 강의에서 재열 수 있다. 다른 기기로 자동 공유하지 않으며, 로그아웃해도 보관 사본은 남는다. ‘보관 원본 삭제’는 브라우저 사본만 삭제한다.

자동 해설은 준비된 설명을 읽는 기능이며 화면을 새로 캡처하지 않는다. 영상·해설 중지는 오래된 음성·질문 응답의 자동 재생도 차단한다. 원본을 조작하는 동안 학생 패널을 열어 둔다. 닫거나 재생 연결이 끊기면 원본을 정지하며 다시 연결해야 할 수 있다.

지문·문장·밑줄·개념 검색, 질문, 복습, 북마크·메모, 노트 내보내기를 사용할 수 있다. 학습 대화를 이용하지 못하면 준비된 자료 기반의 제한적 보조 도구임을 표시한다. 실제 공급자 키는 서버에만 둔다.

음성 인식은 명시적으로 동의한 뒤 사용하며 브라우저 음성 서비스에 음성이 전송될 수 있다. 지원하지 않거나 마이크 사용이 거부되면 타자 창으로 전환한다. Space 명령은 기본으로 켜져 있다. 1회는 영상 재생·정지, 2회는 영상·앱 음성·진행 기능 중지, 3회는 텍스트 명령, 3초 누르기는 음성 명령이다. Tab·Shift+Tab은 현재 패널 안에서 순환하며 Shift만 누르면 이전 항목으로 이동한다. Esc는 패널 키보드 모드 해제, F6는 Chrome 영역 이동이다. 버튼 실행은 Enter를 사용하고 입력칸·체크 상자의 Space는 기본 동작을 유지한다. 외부 사이트 키는 가로채지 않는다. 기본 패널 열기는 Alt+Shift+S, 전체 중지는 Alt+Shift+X이며 Chrome 확장 단축키 설정에서 변경할 수 있다.

속도·앱 음량·자동 해설·스크린리더 설정은 서버에 저장하고, 음성 선택·음높이·키보드 설정은 기기별 계정에 저장한다. 기본은 가용한 한국어 자연·고품질 음성 우선 자동 선택이며 수동 선택도 유지한다. 영상 음량·음소거는 앱 음성과 별도로 조절한다. 실제 음성 품질과 VoiceOver/NVDA는 별도 검증이 필요하다.

## 검증

```bash
PYTHONPATH=apps/api .venv/bin/python -m pytest apps/api/tests/test_extension_access.py -q
.venv/bin/python scripts/verify_extensions_browser.py
.venv/bin/python scripts/verify_preparation_restart.py
.venv/bin/python scripts/verify_student_notes.py
.venv/bin/python scripts/verify_remote_login.py --output docs/verification/student-notes-remote
.venv/bin/python scripts/verify_guardian_entry.py --output docs/verification/student-notes-guardian
.venv/bin/python scripts/verify_extension_production.py
python3 scripts/package_extensions.py
```

브라우저 검증은 임시 DB·프로필·서버와 빌드 패키지를 사용한다. 실제 사이트 플레이어·사람이 듣는 음성·VoiceOver/NVDA 사용은 이 검사와 별개다.

4단계 검사는 1~3단계 흐름과 실제 브라우저 로그인·계정 연결을 누적 검사한다. 시험 MP4 생성을 위해 PATH의 ffmpeg, `SULLIVAN_FFMPEG` 실행 파일 또는 선택적인 Python `imageio-ffmpeg`가 필요하다. 음성 합성·분석 공급자는 모의 경계이고 영상 요소는 실제로 디코딩·재생한다. `SULLIVAN_AXE_SOURCE`에 로컬 axe-core의 `axe.min.js` 경로를 지정하면 확인 화면의 자동 접근성 검사를 함께 실행한다.

## 0.4.3 전체 재검사 오류 수정

전체 재검사의 확정 문제 18건을 수정하고 전용 회귀 18건을 모두 통과했다. 강의 전환 중 원본·진도 경합, 안내 중 지연 재생, 연결 오류 안내, 외부 스크린리더 모드 초기화, 숫자 설정 안내, 명령·초점 복원, 보호자 재시도·자료 한도 오류를 수정했다. 문장별 선택과 명시적 강조 표시도 복원했다. [수정 결과·검사·남은 한계](../../docs/EXTENSION_REAUDIT_FIXES.md)를 참고한다.

0.4.3은 이전 수정 이력이다. 최신 **0.4.9** 빌드는 `dist/extensions/student`, `dist/extensions/guardian`, 로컬 ZIP은 `dist/releases/0.4.9/`다. 두 확장을 새로고침하고 기존 확장 탭·패널을 다시 열어야 한다. 실제 스크린리더·마이크·음질·외부 사이트·유료 분석 품질 검증은 별도다.

## 0.4.1 학생 입력·음성 수정 이력

기존 웹의 흰색·남색·파란색 디자인 토큰을 공유한다. 로그인 전에도 ‘읽기와 키보드 안내’에서 앱 음성 안내, 외부 스크린리더, 초점·상태 음성 끄기를 선택할 수 있다. 앱 안내는 강의 연결과 무관하게 버튼·입력란 이름과 체크 상태·결과·오류를 읽으며 비밀번호 입력값은 읽지 않는다. 처음 소리가 나지 않으면 ‘음성 안내 시작·시험’을 누른다. 외부 스크린리더 모드에서는 앱 음성을 겹쳐 재생하지 않고 결과를 읽기 영역으로 전달한다.

음성 명령 첫 사용은 동의와 Chrome 마이크 허용이 필요하다. ‘마이크 허용·음성 명령 준비’를 누르거나 Space를 3초 누르면 동의 창을 연다. 동의와 마이크 허용 후 다시 Space를 3초 누르고 명령을 말한 뒤 떼거나 음성 명령 버튼을 사용한다. 마이크 허용 대기 중 Esc·중지·강의 전환·로그아웃하면 늦게 허용해도 명령을 자동 시작하지 않는다. 실제 음성 인식 서비스의 지원·연결·기기 마이크 상태에 따라 타자 대체를 안내할 수 있다.

가입과 확장의 실제 분석·학습 대화 허용에서 관리자/이용 코드 입력을 제거했다. 역할별 계정 인증과 강의 소유권·배정·동의·호출 제한은 계속 검사한다. 보호자-학생 연결용 일회용 코드와 비밀번호 복구 코드는 그대로 사용한다. 기존 공개 웹 체험의 별도 코드 정책은 유지한다.

자동 검사는 임시 프로필에 설치한 두 확장, 실제 디코딩 영상과 실제 Chrome 사이드 패널 문서를 검사하며 음성 합성·인식의 서비스 경계는 시험 장치다. 실제 VoiceOver/NVDA 및 사람이 듣는 음질을 검증했다고 표시하지 않는다. 적용은 위 최신 버전 안내를 따른다.
