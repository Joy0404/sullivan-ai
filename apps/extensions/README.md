# 학생·보호자 독립 확장 개발 버전

두 개의 별도 MV3 패키지와 독립 로그인 세션을 제공한다. 0.4는 [개발 계획](../../docs/EXTENSION_DEVELOPMENT_PLAN.md)의 계정 분리·연결·운영 기반까지 구현한 개발 버전이다. 실제 강의 사이트·음성 인식·스크린리더 검증은 진행 전이며 스토어 출시 버전이 아니다. 기존 웹 기능도 유지된다.

## 로컬 실행

프로젝트 루트에서 기존 서버를 실행한다.

```bash
bash START_LOCAL.command --sample
```

다른 터미널에서 패키지를 생성한다.

```bash
python3 scripts/build_extensions.py
```

Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 ‘압축해제된 확장 프로그램을 로드합니다’로 다음 두 폴더를 각각 선택한다.

- `dist/extensions/guardian`: 보호자 아이콘을 누르면 전용 관리 탭이 열린다.
- `dist/extensions/student`: 학생 아이콘을 누르면 전용 사이드 패널이 열린다.

기존 학생·보호자 계정으로 각 프로그램에 로그인한다. 새 로컬 개발 환경에서는 보호자 확장의 계정 생성 → 학생 계정 생성 → 샘플 배정 → 학생 확장 로그인 → 목록 새로고침 → 자료 열기 → 메모 저장을 진행한다. 한쪽 로그아웃이 다른 프로그램의 로그인에 영향을 주지 않아야 한다.

브라우저 로그인은 PKCE 인증과 갱신 자격 회전을 사용한다. 기본적으로 세션 저장소만 사용하며, 명시적으로 ‘내 기기 로그인 유지’를 선택하면 갱신 자격을 확장 전용 로컬 저장소에 보관해 재시작 뒤 복구한다. 사용 중 로그아웃은 서버의 해당 로그인 계열과 기기의 기억도 폐기한다. 서버 연결 실패 시 로그아웃 오류를 표시하고 재시도할 수 있게 세션을 유지한다.

## 보호자 준비와 관리

‘새 강의 준비’에서 자막·지문·표준 분석 JSON, 링크와 보조자료, 원본 파일 실제 분석을 선택한다. 자막·지문은 실제로 처리하고, JSON은 기존 표준 분석 계약으로 검증한다. 링크 분석을 선택하지 않으면 보조자료가 있어야 한다. 실제 분석에는 영상 이용 권한·전송 동의·기존 서버의 분석 연결과 이용 제한이 적용된다.

파일의 실제 분석은 `--sample`이 아닌 기존 실제 분석 실행 방식으로 서버를 시작하고 서버에 공급자 연결을 설정해야 한다. API 키를 확장에 입력하거나 패키지에 넣지 않는다. 원본 파일 분석은 학생에게 영상을 전송하는 기능이 아니다.

준비 상태를 확인한 뒤 ‘결과 확인·배정’에서 학생을 선택한다. 강의 목록에서는 제목·과목·배정 수정, 확인 후 전체 회수, 비공개 자료 재공개를 제공한다. 학생 현황에서는 기본 설정·진도 요약·배정 순서를 관리한다. 회수해도 학생 개인 기록은 삭제하지 않는다.

준비 결과는 DB에 남고 탭을 닫아도 접수한 처리는 서버에서 계속된다. 서버 재시작으로 중단된 작업은 자동 재시도하지 않는다. 다시 준비 버튼에서 자료와 동의를 재선택한다. 현재는 서버 프로세스 하나로 실행해야 하며 다중 워커는 지원하지 않는다.

코드 갱신 뒤에는 기존 로컬 서버를 재시작하고 빌드를 다시 실행한 후 `chrome://extensions`에서 두 확장을 새로고침한다. 서버가 이전 코드로 실행 중이면 새 준비 API를 사용할 수 없다.

## 서버 주소와 운영 경계

기본 서버는 `http://127.0.0.1:8770`이다. 다른 로컬 포트 또는 향후 HTTPS 서버는 빌드 시 지정한다.

```bash
python3 scripts/build_extensions.py --server https://your-sullivan-server.example
```

운영 서버는 `SULLIVAN_PRODUCTION=1`과 `SULLIVAN_EXTENSION_CLIENTS`에 학생·보호자 확장 ID를 각각 등록해야 한다. HTTPS 출처·영속 디스크·단일 프로세스 검사를 통과해야 시작된다. 운영 가입은 초대 코드를 설정한 경우에만 가능하다. 운영에서는 각 역할이 독립 가입하고 보호자의 일회용 코드를 학생이 확인·승인해 연결한다. 복구 코드·로그인 기기 종료·연결 해제도 각 확장에서 제공한다. 자세한 설정과 데이터 이전·원복·스토어 제출 조건은 [운영 안내](../../docs/EXTENSION_OPERATIONS.md)를 따른다. 로컬 개발 서버는 루프백에 바인딩하며 인터넷에 노출하지 않는다.

패키지에 API 키·계정 DB·세션·학생 기록을 포함하지 않는다. 코드·화면의 공통 부분만 공유하고, 상대 역할의 화면·스크립트는 복사하지 않는다. 학생 원본 탭 연결 시 해당 출처의 선택 권한을 요청하며, 모든 사이트를 설치 때 허용하지 않는다. 음성 인식은 별도 동의와 브라우저 허용이 필요하고 화면·오디오 캡처 권한은 요청하지 않는다.

## 학생 수강

강의를 고른 뒤 ‘원본 강의 열고 연결’을 누르거나, 원본 강의 탭 옆의 사이드 패널에서 ‘현재 강의 탭 연결’을 누른다. 선택한 사이트 접근 권한을 허용한 뒤 ‘강의 재생’으로 시작한다. 표준 HTML 영상의 메인 프레임 제어를 구현했으며 실제 YouTube·교차 출처 iframe·유료 플레이어의 호환성을 검증했다고 주장하지 않는다.

로컬 파일은 ‘내 기기의 영상 연결·보관’에서 선택한다. 서버로 업로드하지 않는다. 새 파일 분석 때 저장한 SHA-256·크기와 일치하면 시점 해설과 준비된 자막을 연결한다. 기존 자료에 식별 정보가 없으면 수동 재생·자료 읽기를 사용하거나 보호자가 원본을 다시 준비해야 한다. 브라우저에서 지원하는 코덱이 필요하다.

암호화 보관은 체크한 경우에만 동작하고 100MB 이하를 지원한다. 보관 원본은 동일 Chrome 프로필의 같은 학생 계정·배정 강의에서 재열 수 있다. 다른 기기로 자동 공유하지 않으며, 로그아웃해도 보관 사본은 남는다. ‘보관 원본 삭제’는 브라우저 사본만 삭제한다.

자동 해설은 준비된 설명을 읽는 기능이며 화면을 새로 캡처하지 않는다. 영상·해설 중지는 오래된 음성·질문 응답의 자동 재생도 차단한다. 원본을 조작하는 동안 학생 패널을 열어 둔다. 닫거나 재생 연결이 끊기면 원본을 정지하며 다시 연결해야 할 수 있다.

지문·문장·밑줄·개념 검색, 질문, 복습, 북마크·메모, 노트 내보내기를 사용할 수 있다. 학습 대화를 이용하지 못하면 준비된 자료 기반의 제한적 보조 도구임을 표시한다. 실제 공급자 키는 서버에만 둔다.

음성 인식은 명시적으로 동의한 뒤 사용하며 브라우저 음성 서비스에 음성이 전송될 수 있다. 지원하지 않거나 마이크 사용이 거부되면 타자 창으로 전환한다. 학생 화면의 Space 연속 명령과 Shift 이전 이동은 설정에서 선택한다. 외부 사이트 키는 가로채지 않는다. 기본 패널 열기는 Alt+Shift+S, 전체 중지는 Alt+Shift+X이며 Chrome 확장 단축키 설정에서 변경할 수 있다.

속도·앱 음량·자동 해설·스크린리더 설정은 서버에 저장하고, 음성 선택·음높이·키보드 설정은 기기별 계정에 저장한다. 영상 음량·음소거는 앱 음성과 별도로 조절한다. 실제 음성 품질과 VoiceOver/NVDA는 별도 사용자 검증이 필요하다.

## 검증

```bash
PYTHONPATH=apps/api .venv/bin/python -m pytest apps/api/tests/test_extension_access.py -q
.venv/bin/python scripts/verify_extensions_browser.py
.venv/bin/python scripts/verify_extensions_phase2.py
.venv/bin/python scripts/verify_preparation_restart.py
.venv/bin/python scripts/verify_extensions_phase4.py
.venv/bin/python scripts/verify_extension_production.py
python3 scripts/package_extensions.py
```

브라우저 검증은 임시 DB·프로필·서버와 빌드 패키지를 사용한다. 실제 사이트 플레이어·사람이 듣는 음성·VoiceOver/NVDA 사용은 이 검사와 별개다.

4단계 검사는 1~3단계 흐름과 실제 브라우저 로그인·계정 연결을 누적 검사한다. 시험 MP4 생성을 위해 PATH의 ffmpeg, `SULLIVAN_FFMPEG` 실행 파일 또는 선택적인 Python `imageio-ffmpeg`가 필요하다. 음성 합성·분석 공급자는 모의 경계이고 영상 요소는 실제로 디코딩·재생한다. `SULLIVAN_AXE_SOURCE`에 로컬 axe-core의 `axe.min.js` 경로를 지정하면 확인 화면의 자동 접근성 검사를 함께 실행한다.
