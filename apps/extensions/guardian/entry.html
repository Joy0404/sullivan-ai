보호자 사용 설명서

보호자용은 학생 연결과 강의 준비·배정을 담당합니다. 학생은 학생용 확장에서 자신의 계정으로 수강합니다.

  1. 계정이 있으면 로그인하세요. 처음이면 회원가입 후 복구 코드를 따로 보관하세요.
  2. 로그인 후 일회용 연결 코드를 학생에게 전달하세요. 학생이 학생용 확장에서 보호자와 공유 범위를 확인하고 동의합니다.
  3. 연결된 학생에게 사전 준비된 샘플을 배정하세요. 샘플은 새 영상 분석 없이 사용할 수 있습니다.

지금은 아래 버튼으로 시작할 수 있습니다. 자세한 설명은 선택해서 펼치거나, 이후 ‘보호자 설명서’에서 다시 볼 수 있습니다.

로그인 상태를 확인하고 있습니다. 잠시 기다려 주세요.

전체 보호자 사용 설명서 펼치기

1. 보호자 계정과 학생 연결

처음 이용하면 회원가입을 선택해 보호자 계정을 만드세요. 표시되는 복구 코드를 따로 보관한 뒤 로그인합니다. 계정이 있으면 로그인만 선택하세요.

로그인 후 ‘새 일회용 연결 코드 만들기’를 누르고 학생에게 코드를 전달하세요. 학생이 학생용 확장에서 처음 한 번 가입·로그인하고 코드를 입력하면, 보호자 이름과 공유 범위를 확인해 연결할 수 있습니다. 연결 코드는 10분 동안 한 번 사용할 수 있습니다.

로컬 개발 환경에서는 ‘학생 계정 만들기’로 시험용 계정을 만들 수도 있습니다. 실제 계정과 비밀번호를 다른 사람과 공유하지 마세요.

2. 강의를 준비하고 결과 확인하기

  • 빠르게 시작하려면 ‘샘플 강의 배정’에서 학생과 사전 준비된 샘플을 선택하세요. Gemini 키 없이 사용할 수 있으며, 새 영상을 분석한 결과가 아닙니다.
  • ‘새 강의 준비’에서는 자막·지문·분석 JSON, 영상 링크, 로컬 파일 재생용 등록, 원본 파일 실제 분석을 선택할 수 있습니다. 자료를 넣고 ‘자료 준비 시작’을 누르세요.
  • 재생용 링크·파일 등록이나 자막·지문 추가만 한 경우 ‘영상 분석 미실행’입니다. ‘Gemini 분석 완료’는 서버가 실제 처리를 완료한 경우에만 표시합니다. 분석 중·실패·사전 준비 샘플·기록 확인 불가도 구분합니다.
  • 실제 영상 분석에는 공급자 설정, 이용 권한과 임시 전송 동의가 필요합니다. API 키는 보호자 화면에 입력하지 않습니다. 기본 재생용 원본은 브라우저에 둡니다.

준비가 끝나면 ‘결과 확인·배정’에서 내용을 확인하세요. 화면에서 확인한 중요한 정보만 설명하고, 불확실한 숫자·단위·문구는 해당 위치의 보류 안내로 알립니다. 문제 보호 모드에서는 정답에 해당하는 화면 내용을 제공하지 않습니다.

3. 학생에게 배정하고 수강 시작하기

준비 결과에서 배정할 학생을 선택하고 ‘확인한 자료를 학생에게 배정’을 누르세요. 미리보기만 열어서는 배정되지 않습니다. 파일 강의는 학생에게 같은 원본 파일도 별도로 전달해야 합니다.

학생은 학생용 확장에서 배정된 강의를 열고 원본 탭이나 직접 선택한 영상 파일을 연결한 뒤 재생합니다. 해설은 준비된 자료의 시점에 맞춰 제공하며 현재 화면을 새로 분석하지는 않습니다. Chrome에서 지원하는 형식과 접근 허용 범위 안에서 재생합니다.

4. 학생 로그인과 학습 설정 지원

학생이 처음 한 번 로그인하고 보호자 연결 및 해당 Chrome 기기의 로그인 지원을 승인하면, 보호자는 ‘학생 로그인 지원’에서 학생 이름을 선택하고 ‘선택한 학생 로그인’을 누를 수 있습니다. 요청은 승인된 학생 기기에 전달하며 보호자 화면으로 학생 계정을 열지 않습니다. 학생 Chrome이 켜져 있어야 하며 요청은 5분 뒤 만료됩니다.

‘학생 설정과 학습 현황’에서 자동 해설, 문제 보호, 읽기 속도·음량, 외부 스크린리더 사용 등을 설정할 수 있습니다. 외부 스크린리더 모드는 학생 앱 음성의 중복 낭독을 피하도록 읽기 영역으로 안내합니다.

학습 현황은 저장된 위치와 기록 수를 보여 줍니다. 실시간 감시나 완료율이 아니며 학생의 개인 메모 본문은 보내지 않습니다. 학생의 학습 선택을 존중하며 필요한 설정만 함께 확인하세요.

5. 다시 보기와 문제 해결

학생에게 강의가 보이지 않으면 학생 연결·배정·공개 상태를 확인하고 학생 확장에서 목록을 새로고침하세요. 원본 파일 연결이 안 되면 같은 파일인지 확인하세요. 준비 작업이 실패하거나 서버 재시작으로 중단되면 결과를 확인하고 자료와 동의를 다시 선택해 요청하세요.

Tab과 Shift+Tab으로 항목을 이동하고 Enter 또는 Space로 버튼을 선택합니다. 오류 안내를 확인하고 수정하세요. 이후에도 화면 위 ‘보호자 설명서’를 선택하면 로그인 전후 언제든 이 설명서를 다시 볼 수 있습니다.
