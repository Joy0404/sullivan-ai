학생과 강의 준비

강의를 준비하고 결과를 확인한 뒤 학생에게 배정하세요. 실제 영상 분석은 별도 동의와 서버 연결이 필요합니다. 학생의 영상 수강 기능은 기존 웹에서 계속 이용할 수 있습니다.

학생과 연결

학생은 학생용 확장에서 자신의 계정으로 가입합니다. 아래 일회용 코드를 학생에게 전달하면 학생이 보호자 이름과 공유 범위를 확인한 뒤 연결합니다.

10분 동안 한 번 사용할 수 있습니다. 새 코드를 만들면 이전 미사용 코드는 만료됩니다. 코드를 선택해 복사할 수 있습니다.

    학생 계정 만들기

    개발 1단계에서는 기존과 같이 보호자가 학생 계정을 만듭니다. 독립 계정 연결 코드는 후속 단계에서 제공합니다.

    영문·숫자·밑줄·마침표·하이픈, 3자 이상.

    비밀번호는 8~128자로 입력하세요.

    연결된 학생

      샘플 강의 배정

      새 AI 분석을 실행하지 않습니다. 원본 영상의 재생과 자동 해설은 현재 기존 웹에서 이용하세요.

      새 강의 준비

      필수 표시가 있는 항목을 입력하세요. 자료 방식은 파일 또는 직접 입력 지문 중 하나 이상이 필요합니다. 실제 분석을 선택하지 않은 링크에도 자막·지문·JSON 중 하나가 필요합니다.

      SRT·VTT 자막, TXT·MD 지문, 표준 분석 JSON을 지원합니다. 파일당 30만 자, 전체 100만 자 이하. JSON은 한 개만 선택하세요.

      분석을 요청하지 않으면 함께 넣은 자막·지문·JSON으로 학습자료를 준비합니다. 링크만 등록해서 분석 완료로 표시하지 않습니다.

      100MB 이하. 원본은 동의한 실제 분석을 위해 임시 전송한 뒤 삭제합니다. 학생에게 원본 파일을 전달하거나 서버에 보관하는 기능은 아닙니다.

      서버의 기존 이용 제한을 그대로 적용합니다. 공급자 API 키는 여기에 입력하지 마세요.

      준비 작업과 분석 결과

      화면을 닫아도 접수된 작업은 서버에서 처리합니다. 서버 재시작으로 중단되면 자료를 다시 선택해 요청해야 합니다.
