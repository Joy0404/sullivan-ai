강의 목록

배정된 강의를 고르고 원본 탭이나 직접 선택한 영상을 연결하세요. 해설은 준비된 분석 자료를 재생 시점에 맞춰 읽으며, 현재 화면을 새로 촬영·분석하지 않습니다.

학생 사용법

Tab은 다음, Shift 또는 Shift+Tab은 이전 항목입니다. Enter로 버튼을 실행합니다. Esc는 패널 키보드 모드를 해제하고 F6로 Chrome 영역을 이동할 수 있습니다.

홈과 수강 화면에서 Space 한 번은 영상 재생·정지, 두 번은 영상·음성·진행 기능 중지, 세 번은 텍스트 명령입니다. 3초 누른 채 명령을 말하고 떼면 실행합니다. 처음 한 번 마이크 동의·허용이 필요합니다.

강의 목록, 1번 강의 열어줘, 영상 재생, 세 줄 요약, 다음 문단, 원래 듣던 곳으로, 학습 기록, 사용법처럼 말하거나 입력하세요. 입력칸의 Space는 띄어쓰기이며 설명이나 요청 중 두 번 누르면 중지합니다.

원본 파일은 학생 기기에 따로 전달받아 선택합니다. 식별이 일치해야 자동 해설을 켭니다. 소리가 없으면 음성 안내 시작·시험을 누르세요. 외부 스크린리더는 읽기 방식에서 선택합니다.

강의가 없으면 보호자의 배정과 공개 상태를 확인하고 목록을 새로고침하세요. 저장 실패 시 학습 기록 다시 저장 버튼으로 재시도하세요. 새 필기는 이 기기에 초안을 보존하며 다시 저장할 수 있습니다. 기존 메모·위치·북마크·밑줄도 그대로 보존합니다. API 키·비밀번호·원본을 문의 메시지로 보내지 마세요.

    내 필기

    학생이 직접 작성하는 개인 노트입니다. 자동 교정·요약을 하지 않고 AI 공급자나 보호자에게 본문을 보내지 않습니다. 저장·닫기는 강의를 재생하지 않습니다.

    학생 작성 영역

    자동 저장합니다. 실패한 초안은 이 기기의 내 계정에 보존됩니다. 개인 기기에서 이용하세요. 다른 화면의 변경과 충돌하면 초안을 새 필기로 보존할 수 있습니다.

    이 필기 항목을 삭제할까요? 연결 원문과 기존 메모는 보존됩니다.

      보호자 연결과 공유 범위

      연결하면 보호자가 강의를 배정하고 학습 위치·기록 개수 요약·기본 설정을 확인할 수 있습니다. 메모·질문 원문은 공유하지 않습니다.

      10분 안에 입력하고, 다음 화면에서 보호자 이름을 직접 확인하세요.

      연결 승인

        연결을 해제하면 이 보호자가 배정한 강의 이용이 끝나고 보호자는 이후 내 기록을 조회할 수 없습니다. 내 개인 기록은 삭제하지 않습니다. 연결을 해제할까요?

        강의 영상 연결과 보관

        파일 강의는 내 기기의 영상 선택, 링크 강의는 원본 열기 또는 현재 탭 연결을 선택하세요. 보호된 스트림을 다운로드하지 않습니다.

        영상을 아직 연결하지 않았습니다.

        내 기기의 영상 연결·보관

        Chrome이 재생할 수 있는 영상은 파일 종류 정보가 없어도 실제로 열어 확인합니다. 선택한 원본은 서버에 전송하지 않습니다. Chrome 미지원 코덱·손상 파일은 원인과 대체 형식을 안내합니다. 분석 원본 식별과 선택형 암호화 보관은 100MB 이하이며, 원본 식별 정보가 없으면 수동 재생과 준비 자료 읽기를 제공합니다.

        연결한 영상의 위치를 저장합니다. 숫자를 바꿔 저장하면 연결한 영상도 해당 위치로 이동합니다. 영상이 없으면 위치만 기록합니다.

        음성·해설·키보드 설정

        자동 선택은 Chrome에 설치된 한국어 Natural·Neural·고품질 음성을 우선합니다. 기존 Space 음성 명령은 그대로 사용하며, 외부 스크린리더는 선택해서 사용할 수 있습니다.

        음성 선택·음높이·키보드 설정은 이 기기의 내 계정에 저장합니다. Tab과 Shift+Tab은 패널 안에서 순환하고 Shift만 눌러도 이전 항목으로 이동합니다. Esc로 키보드 모드를 해제할 수 있습니다. 음질은 설치된 브라우저 음성에 따라 다릅니다. 강의 사이트의 Space·방향키는 가로채지 않습니다. Chrome 확장 단축키 설정에서 패널 열기·전체 중지 키를 변경할 수 있습니다.

        타자 명령

        명령을 입력하고 Enter로 실행하세요. Esc는 취소입니다.

        음성 명령을 위한 마이크 허용

        음성 명령은 Chrome의 음성 서비스로 음성이 전송될 수 있습니다. 동의하면 마이크 권한을 요청하고 음성 명령을 시작합니다. 타자 명령은 Space 세 번으로 사용할 수 있습니다.
