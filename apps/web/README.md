# Sullivan AI Web

의존성 없는 HTML·CSS·JavaScript 접근성 플레이어입니다.

```bash
cd apps/api && uvicorn app.main:app --port 8000
```

FastAPI 서버가 이 폴더를 같은 주소에서 함께 제공하므로, 웹은 포트 없이 상대 경로(`/v1/...`, `/health`)로 API를 호출합니다. 로컬에서는 `http://localhost:8000`을 엽니다. 영상 파일은 `URL.createObjectURL`로 브라우저 안에서만 재생되며 서버에 업로드되지 않습니다. SRT/VTT/TXT/MD는 브라우저가 텍스트로 읽어 API에 전달하고, 분석 JSON은 STT/OCR 어댑터의 표준 출력으로 처리합니다.

브라우저 기능:

- 타임스탬프 기반 자동 Pause → 한국어 TTS → Resume
- 키보드 접근 가능한 타임라인과 문장 탐색
- Space 2초 누름→명령 목록 안내→두 번째 알림음→누르는 동안 인식→키를 떼면 실행하는 전역 Web Speech API 명령(지원 브라우저만)
- Space를 1초 안에 두 번 눌러 TTS·명령 안내를 끄고 강의로 복귀, YouTube 기본 Space 키보드 제어 비활성화
- 음성 또는 텍스트로 요약·용어 카드·복습 계획·퀴즈·발표문·개념 지도 생성
- 요약과 학습 대화 결과 TTS 안내 및 재생 일시정지·자동 재개
- 긴 지문 문단별 역할·흐름 탐색, 문단 밑줄 저장, 밑줄 문단 음성 재청취
- IndexedDB 기반 로컬 강의 보관함: 로컬 원본·요약 저장, YouTube 원본 링크·요약 저장, 음성 요청 재열기
- Gemini 행동 에이전트: 현재 강의·재생 위치를 관찰해 답변, 요약 낭독, 구간 이동, 화면 해설, 문단 재청취, 정지 중 하나를 선택하고 설리번 안전 계층이 실행
- Gemini 키가 없거나 연결에 실패하면 제한적 로컬 보조 학습 대화로 자동 전환
- 접근성 복습과 판단 근거 표시
- 문제 보호 모드 선택 시에만 최종 정답 보류
- ARIA 라이브 영역과 모션 감소 설정
