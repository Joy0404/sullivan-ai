학생의 첫 강의를 준비하는 순서

학생 계정 만들기, 강의 준비하기, 학생에게 배정하기.
샘플로 먼저 연습한 뒤 학생에게 맞는 자료를 준비해 주세요.

로그인 화면으로1단계부터 살펴보기

필요한 단계로 이동

  1. 보호자 계정·로그인
  2. 학생 계정 만들기
  3. 학생별 기본 설정
  4. 강의 준비하기
  5. 분석 결과 확인
  6. 학생에게 배정하기
  7. 학생 키보드 사용법
  8. 자주 묻는 질문·문제 해결

각 단계에 실제 샘플 모드 화면이 있습니다. 이미지를 선택하면 원래 크기로 볼 수 있습니다.

  1. 1단계. 보호자 계정 만들기·로그인

    1. 로그인 화면을 엽니다. 처음 설치된 환경에서는 ‘처음 보호자 계정 만들기’가 표시됩니다.
    2. 로그인 이름, 8자 이상의 비밀번호와 보호자 이름을 입력해 계정을 만듭니다.
    3. 계정이 이미 있다면 ‘보호자 로그인’을 선택하고 기존 로그인 이름과 비밀번호를 입력합니다.

    현재는 로컬 계정을 쓰는 시제품입니다. 공개 회원가입은 제공하지 않습니다. 최초 설정이 끝난 환경에서 계정이 없다면 시제품을 안내한 팀 담당자에게 문의해 주세요.

  2. 2단계. 학생 계정 만들기

    1. 보호자 준비실의 ‘학생 관리’에서 ‘새 학생 계정 만들기’를 펼칩니다.
    2. 학생 이름, 학생 로그인 이름, 8자 이상의 비밀번호를 입력합니다. 로그인 이름은 영문·숫자·밑줄·마침표·하이픈으로 3~60자입니다.
    3. ‘학생 계정 만들기’를 누릅니다. 학생에게 로그인 이름과 비밀번호를 직접 알려 주세요.

  3. 3단계. 학생별 기본 설정

    1. ‘학생별 기본 설정’을 펼치고 설정할 학생을 고릅니다.
    2. 자동 화면 해설과 문제 보호 모드를 확인합니다. 문제 보호 모드에서는 최종 정답을 가립니다.
    3. 앱 음성 안내 또는 스크린리더 안내를 선택합니다. 읽기 속도·음량을 맞추고 ‘학생 설정 저장’을 누릅니다.

    VoiceOver·NVDA를 쓰면 ‘앱 음성 대신 스크린리더 안내’를 선택해 음성이 겹치지 않게 합니다. 실제 사용자 환경에서의 낭독 검증은 아직 진행 전입니다.

  4. 4단계. 강의 준비하기

    처음에는 샘플로 연습하기

    보호자 준비실에서 ‘과학 샘플 미리보기’ 또는 ‘역사 샘플 미리보기’를 선택합니다. 샘플은 사전 준비된 결과이며, 선택한 영상을 새로 분석하지 않습니다. 유료 API 인증이 없어도 사용할 수 있습니다.

    내 강의와 자료 준비하기

    ‘강의 준비하기’ 영역의 ‘내 강의 자료 준비’를 엽니다. 1단계에서 제목·과목·출처를 입력하고, 2단계에서 샘플·영상 링크·영상 파일과 학습자료를 고릅니다. 자막(SRT·VTT), 지문(TXT·MD), 분석 JSON만 준비할 수도 있습니다. 3단계에서 입력 요약·보호 설정·이용 권한을 확인합니다.

    실제 분석에는 운영자가 설정한 분석 환경과 체험 코드, 이용·분석 권한 확인, 별도의 분석 동의가 필요합니다. 준비되지 않으면 실제 분석은 실행되지 않습니다. 유료 강의나 DRM을 우회하는 자료는 사용할 수 없습니다.

    실제 분석이 설정된 환경에서는 이용 권한과 분석 동의를 확인한 뒤 ‘분석 시작’을 누릅니다. 샘플은 2단계에서 ‘샘플로 시작’을 고른 뒤 마지막 단계의 ‘샘플 결과 열기’를 누릅니다. 샘플은 새 영상을 분석하지 않습니다.

    원본 영상 전송·저장 안내

    기본값에서는 원본을 전송하지 않습니다. 별도 동의한 실제 분석에서는 로컬 영상을 임시 전송하고 분석 뒤 삭제를 시도합니다. 삭제가 확인되지 않으면 완료 처리하지 않고 알립니다. 공급자 쪽 사본은 최대 48시간 남을 수 있습니다.

    ‘로컬 영상 원본 저장’을 선택한 경우에만 원본이 브라우저 보관함에 남습니다. 파일 강의는 같은 브라우저·주소·포트에서 이용해 주세요.

  5. 5단계. 분석 결과 확인

    1. 샘플 미리보기 또는 실제 분석 결과에서 강의 제목과 샘플 여부를 확인합니다.
    2. ‘강의 화면’에서 해설을, ‘핵심 탐색’에서 개념과 지문을 확인합니다.
    3. ‘접근성 복습’과 ‘안전·판단 근거’에서 화면 정보의 시각·이유와 보류 상태를 확인합니다. 확신이 낮거나 문제 모드의 정답인 후보 문구는 공개하지 않습니다.

  6. 6단계. 학생에게 배정하기

    1. 결과 화면의 ‘학생에게 제공하기’에서 제목·과목과 배정할 학생을 확인합니다.
    2. ‘배정하고 준비 완료’를 누릅니다. 미리보기만 열면 학생에게 배정되지 않습니다.
    3. 보호자 준비실의 ‘강의’에서 학생 이름과 ‘준비 완료’를 확인합니다. 학생별 기본 설정에서 학생을 고른 뒤 해당 강의의 ‘관리’를 펼치고 ‘순서 앞당기기’·‘순서 뒤로 보내기’로 순서를 바꿉니다.

    빠르게 연습하려면 ‘강의 준비하기’의 ‘샘플로 연습하기’를 펼칩니다. ‘샘플 바로 배정’에서 학생과 샘플을 고르고 ‘선택한 학생에게 샘플 배정’을 눌러도 됩니다.

  7. 7단계. 학생은 이렇게 써요

    보호자 계정에서 로그아웃한 뒤 ‘학생 로그인’을 선택합니다. 학생 계정으로 로그인하고 최초 사용법을 확인합니다. ‘강의 듣기’에서 배정된 강의를 고른 뒤 ‘강의 재생’을 누릅니다.

    Tab / Shift+Tab
    다음 / 이전 버튼으로 이동
    Enter / Space
    선택한 버튼 실행. 링크는 Enter로 열기
    왼쪽 / 오른쪽 방향키
    강의에서 10초 전 / 앞으로 이동. 입력칸에서는 글자 이동
    빠른 명령 영역의 Space
    길게 눌러 말하고 떼기. 두 번은 영상·음성 중지, 세 번은 타자 명령
    타자 명령의 Enter / Esc
    명령 보내기 / 취소하고 돌아가기. Space는 띄어쓰기

    지문·문단 듣기, 원하는 내용 찾기, 질문하기도 직접 선택합니다. 음성 인식이 어려우면 타자 명령을 사용해 주세요.

  8. 8단계. 자주 묻는 질문·문제 해결

    학생에게 강의가 보이지 않아요

    학생 이름과 ‘준비 완료’를 확인해 주세요. 학생 화면에서 ‘강의 듣기’를 다시 누르면 배정 목록을 새로 확인합니다. 보호자와 학생을 바꿀 때는 로그아웃한 뒤 다시 로그인합니다.

    음성이 겹치거나 들리지 않아요

    앱 음성 안내와 외부 스크린리더 설정을 확인합니다. PC 음량도 확인해 주세요. 학생 화면의 ‘사용법 알려줘’에서 키보드 안내를 다시 볼 수 있습니다.

    실제 분석이 실행되지 않아요

    시제품의 샘플 전용 실행에서는 실제 분석이 꺼져 있습니다. 별도 분석 설정·체험 코드·이용 권한·분석 동의가 필요합니다. 먼저 샘플로 학습 흐름을 확인해 주세요.

    이용 환경·비용·문의

    PC와 최신 Chrome을 사용해 주세요. 샘플은 유료 API 인증 없이 동작합니다. 실제 분석에는 공급자 비용이 발생할 수 있으며 공개 요금제는 아직 없습니다. VoiceOver·NVDA 실사용 검증은 진행 전입니다.

    문제가 계속되면 시제품을 안내한 SWIFT 팀 담당자에게 사용 환경과 막힌 단계를 알려 주세요. 비밀번호나 영상 원본은 보내지 마세요.
