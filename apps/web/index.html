Gemini는 어디에 사용되나요?

공개 YouTube·영상 파일 링크 또는 별도 동의한 로컬 영상의 음성·화면을 분석하고, 학습 대화에서 요청을 판단해 다음 행동을 고를 때 사용합니다. 로컬 영상은 임시 전송 후 삭제를 요청하며, 분석 결과는 설리번의 개인정보·시각 근거·문제 보호 규칙이 다시 검증합니다.

공개·소유 영상만 지원합니다. 유료 강의, 로그인·DRM 우회 링크는 분석하지 않습니다.

분석 동의 자세히

체크한 경우에만 실제 분석을 실행합니다. 업로드 영상은 분석 직후(성공·실패·시간 초과 모두) 서버 임시 파일과 Gemini 파일의 삭제를 시도하며, 삭제를 확인하지 못하면 화면에 알려 드립니다. 이 경우 Gemini 쪽 사본은 공급자 정책에 따라 최대 48시간 남을 수 있습니다.

체험 코드가 필요한 경우
