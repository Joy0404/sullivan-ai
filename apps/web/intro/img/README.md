# 소개·가이드 화면의 출처

모든 PNG는 이 저장소의 실제 앱을 샘플 모드로 실행해 직접 캡처했다.
외부 레퍼런스 이미지·로고·사진은 포함하지 않는다.

- 촬영: 2026-11-04, Chrome, Hallmark `capture.mjs`의 로컬 CDP 캡처
- 환경: 임시 계정 저장소, 예시 보호자·체험 학생 계정
- 샘플: 사전 준비된 과학 ‘별의 진화’ 결과
- 원본 영상의 새 분석이나 공급자 호출은 하지 않았다.
- 화면 캡처 때 외부 YouTube 재생과 음성 합성 경계만 모의 처리했다. 캡처는 영상 분석 결과의 증거가 아닌 실제 앱 UI 안내용이다.
- `student-actions-mobile.png`는 폭 390px에서, 나머지는 폭 1280px에서 해당 UI 영역을 캡처했다.
- 이미지 속 입력란·버튼 조작은 이미지 밖의 가이드 본문에서도 설명한다. 이미지는 필수 안내의 유일한 전달 수단이 아니다.
- 개인정보·비밀번호·실제 계정 데이터는 포함하지 않는다.

촬영 영역과 키보드 배정 흐름의 검증 결과는
[`t1-sample-flow-results.json`](../../../../docs/verification/t1-sample-flow-results.json)에 기록했다.
이미지는 앱 UI가 변경되면 해당 단계를 다시 실행해 촬영한다.
