# 대회 시연 대본

## 0:00–0:35 문제와 SDG 4

“인터넷 강의에서 강사는 말만 하지 않습니다. 식을 쓰고, 부호를 고치고, 긴 지문에 밑줄을 긋습니다. 기존 TTS는 전부 읽고 영상 요약은 나중에 줄여주지만, 지금 화면으로만 전달된 정보를 되찾게 하지는 못합니다. Sullivan AI는 SDG 4의 포용적이고 형평성 있는 교육을 ‘답 대신 접근’을 제공하는 방식으로 구현합니다.”

## 0:35–0:55 정직한 MVP 범위

첫 화면의 영상 로컬 재생과 권리 확인을 가리킨다.

“원본 영상은 이 브라우저 밖으로 보내지 않습니다. 오늘은 동일한 결과가 나오는 분석 패키지로 에이전트 판단을 시연하고, 실제 공급자는 같은 계약에 연결합니다. 데모를 실제 영상 AI라고 부르지 않겠습니다.”

`샘플 영상 보기`에서 샘플 2 역사 영상을 누른다.

## 0:55–1:35 자동 정지·화면 해설

영상 상태의 `다음 2:20`을 보여주고 2분 20초 자동 해설 구간을 시연한다.

“강의는 계속 재생되지만 Sullivan AI는 조선·일본·명과 여진의 배경 비교처럼 화면 구조가 학습에 꼭 필요한 순간을 스스로 찾습니다. 해당 시점에 영상을 멈추고 세 나라의 관계를 말한 뒤 이어서 재생합니다.”

12분 7초 침입 경로 마커를 선택한다.

“부산에서 충주·한양·평양으로 향한 침입 경로와 선조가 의주로 향한 피란 경로를 지도 방향과 함께 전달합니다.”

## 1:35–2:00 안전 보류

판단 근거 화면에서 `HOLD`를 보여준다.

“기준 72%보다 낮은 화면 글자는 그럴듯한 추측조차 학생에게 보여주지 않습니다. 공개 설명과 음성 후보에서 제거합니다. 문제 모드를 켜면 정답도 같은 경로로 차단합니다.”

## 2:00–2:45 핵심 개념 음성 탐색

핵심 탐색으로 이동해 `정묘호란과 병자호란 비교`를 검색하고 `말하기`를 누른다. 강사 구간이 먼저 나온 뒤 AI 재설명이 이어지는 것을 보여주고 `강사·AI 재생 멈춤`도 누른다.

“강사가 강조한 35개 핵심 키워드와 흐름을 비시각적으로 탐색합니다. 검색 결과만 읽는 것이 아니라 원래 강사 설명을 먼저 들은 뒤 AI가 다시 정리하므로 맥락과 복습을 함께 보존합니다.”

## 2:45–3:10 접근성 복습

접근성 복습 화면으로 이동한다.

“일반 요약이 아니라 강의 중 화면으로만 제시된 정보와 강조 문장을 타임스탬프와 함께 남깁니다. 항목을 누르면 원래 위치로 돌아갑니다.”

## 3:10–3:30 마무리

“Sullivan AI의 혁신은 OCR이나 TTS 하나가 아닙니다. 강사가 말한 것과 화면에 있는 것을 비교하고, 필요한 순간에만 개입하며, 눈으로 찾는 학습 행동을 되돌려주는 에이전트입니다. 장벽은 없애되 답은 대신하지 않습니다.”

## 실패 대비

- API가 꺼짐: `docker compose up` 후 새로고침
- 브라우저 음성이 없음: 화면 텍스트와 ARIA 라이브 영역으로 계속 시연
- 마이크 권한 거부: 빠른 명령 버튼 또는 텍스트 입력 사용
- 영상 또는 API 준비 실패: 내장 샘플 데이터로 해설·요약·학습 노트 실행 가능
