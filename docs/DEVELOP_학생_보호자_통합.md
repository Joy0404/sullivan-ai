# 학생·보호자 앱 — Develop 통합

2026년 11월 3일

**2026년 11월 4일 수정:** 강의 진입·저장 위치 복원 시 자동 재생을 제거했습니다. YouTube를 준비 상태로 두고 ‘강의 재생’으로 시작하며, 재생 전 방향키 이동도 정지 상태를 유지합니다. 설정의 체크박스가 가로 전체 너비로 늘어나던 공통 입력 스타일을 수정하고, 체크박스·설명·음성 시험 버튼을 별도 행으로 정리했습니다.

이전 검사에서는 YouTube 모의 플레이어가 항상 일시정지 상태로 시작해 실제 준비 상태의 자동 재생을 놓쳤습니다. [YouTube 공식 API 설명](https://developers.google.com/youtube/iframe_api_reference#seekTo)에 맞춰 준비 상태와 `seekTo`의 재생 동작을 모의 검사에 반영했습니다. 신규 회귀 검사에서 최초 진입·1분 32초 위치 복원·명시적 재생·재생 전 10초 이동, 320/390/640/1280px 설정 배치와 이름·체크 상태를 확인했습니다. 전체 검사 110개 통과·4개 건너뜀, 32개 화면 axe 위반 0건입니다. 실제 YouTube·스크린리더 음성은 미검증입니다.

## 이번 요청

- 수강 버튼을 **강의 재생 → 영상·해설 모두 중지 → 현재 화면 다시 설명** 순서로 정리했습니다.
- 10초 전·후 버튼은 HTML과 이벤트 처리에서 제거했습니다. **왼쪽·오른쪽 방향키로 10초 이동**하며, 입력칸·선택 목록·명령창에서는 원래 키 동작을 유지합니다.
- 로그인 화면에 **학생 로그인 기본 초점**을 지정했습니다. 초기 데이터 확인 후에도 버튼 이름을 한 번 요청하도록 보완했습니다. 느린 응답이 사용자가 옮긴 초점을 되돌리지 않습니다.
- 브라우저가 사용자 조작 전 자동 음성을 차단할 수 있습니다. 이 경우 상태 안내를 확인하고 ‘로그인 음성 시작·시험’을 한 번 누르세요. 앱이 브라우저의 음성 허용 정책을 우회하지는 않습니다.

## 함께 통합한 실행 코드

기존 Develop에는 소개·실행기에 표시된 학생·보호자 기능의 일부 구현 파일이 없었습니다. 현재 로컬 화면이 저장소에서도 실행되도록 다음을 함께 반영했습니다.

- 보호자·학생 계정 연결, 서버 권한 검사, 준비된 강의 배정·순서 관리, 학습 위치·기록 저장.
- 학생의 강의·지문·검색·질문 흐름, 보호자의 준비·배정 화면, 화면별 첫 초점과 Shift 이전 이동.
- 버튼 음성 중 일시정지·완료 후 이어 듣기, 빠른 탐색의 오래된 음성 취소, 직접 중지 후 재생 방지.
- 영상 내부 버튼을 Tab·Shift 탐색에서 제외하고 앱의 학습 조작으로 연결.
- 단일 샘플 카탈로그를 사용하는 미리보기·서버 배정, 명령창과 Space 길게·두 번·세 번 처리.
- 실행 중인 같은 로컬 작업본을 재사용하는 실행기와 관련 회귀 검사.

**보존:** Develop의 Gemini 공급자 두 파일·모델 선택·API 호출 경로·폴백과 배포 설정. 저확신도 보류·문제 보호·개인정보·원본 삭제 정책은 유지하며 파생 지문·요약 경로의 보호도 반영했습니다. 사용자 계정 DB, 키, 환경 파일, 영상, 캐시, 로컬 ZIP은 업로드 대상에 넣지 않았습니다.

| 접근성 | **32개 화면**, 실제 Tab·Shift+Tab·접근성 이름·상태 확인, axe 자동 위반 **0건** |
| 이번 버튼 순서 | 세 버튼의 이름·DOM 순서와 Tab·Shift 이동 확인 |
| 로그인 시작 | 학생 로그인 첫 초점, 첫 음성 요청 한 번, 보호자 선택 시 중지·학생 선택 시 지속 확인 |
| 음성·영상 탐색 | 안내 전 정지·종료 후 재개, 지연·실패·오래된 완료 신호, 입력 키 보존, 영상 내부 12개 버튼 건너뛰기 확인 |
| 로컬 영상 | 실제 브라우저 영상 스트림 일시정지·재개와 암호화 WebM 재생 확인 |
| 기본 서비스 검사 | 임시 로컬 계정으로 자산·인증 차단·샘플 분석·동의 게이트 통과 |

음성 합성·마이크·YouTube는 모의 경계로 검사했습니다. **실제 VoiceOver/NVDA, 사람이 듣는 음성, 실제 YouTube·Gemini 호출은 미검증**입니다. 브라우저 자동 검사 결과가 실제 청각·스크린리더 검증을 대체하지는 않습니다.

## 실행

```bash
bash START_LOCAL.command --sample
```

http://127.0.0.1:8770 에 접속합니다. 새 작업본에는 계정이 없으므로 최초 한 번 보호자 계정을 만들고 학생을 연결합니다. 이미 실행 중인 이전 로컬 작업본의 계정 데이터는 원래 폴더에 유지됩니다.

검사:

```bash
sh scripts/verify_all.sh
python scripts/verify_keyboard_navigation.py
python scripts/verify_login_assignment.py
python scripts/verify_audio_navigation.py
python scripts/verify_roles_browser.py
```

브라우저 검사는 개발용 Playwright/Chromium을 사용합니다. axe 검사는 `SULLIVAN_AXE_SOURCE`에 로컬 axe-core 경로를 지정합니다. 테스트는 임시 DB를 사용합니다. 외부 스크린리더 모드에서는 초점 이동 시 강의를 멈추고 재생 버튼으로 직접 이어 듣습니다.
