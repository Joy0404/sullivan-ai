# Chrome 강의 연결 확대 — 0.4.7

사용 기준은 Chrome, 사용자가 제공하는 강의 링크 또는 로컬 영상, 기존 단축키, 가용한 한국어 자연 음성 자동 선택이다. 사이트·OS·스크린리더 정보를 다시 받아야만 개발을 진행하는 조건은 제거했다. 실제 외부 서비스와 기기별 호환 근거는 자동 검사와 구분한다.

## 확인한 원인과 수정

| 문제 | 원인 | 수정 |
| --- | --- | --- |
| 일반 강의 페이지를 등록해도 원본 연결이 안 됨 | 재생 주소가 YouTube·직접 영상만 보존하고 일반 페이지를 버림 | 확장에서는 일반 HTTP(S) 페이지와 SPA 경로도 보존·배정·연결 |
| iframe·Shadow DOM 플레이어를 못 찾음 | 메인 문서의 video만 탐색 | 허용된 프레임, 동일 출처 iframe, 열린 Shadow DOM 탐색. 주 영상 선택 후 동일 문서·요소에 연결 고정 |
| 다른 도메인의 영상 제공자 권한을 해결 못 함 | 상위 사이트의 권한만 요청 | 필요한 출처만 표시하고 기본 버튼의 Enter로 추가 허용·거절·재시도. Chrome의 [사용자 동작에 따른 권한 요청](https://developer.chrome.com/docs/extensions/reference/api/permissions) 규칙 적용 |
| 확장 실제 분석도 공개 웹의 샘플 영상 제한에 걸림 | 공개 체험 제한을 인증된 확장 요청에도 적용 | 확장의 보호자 인증·동의·호출 제한을 통과한 요청만 일반 URL 분석 어댑터로 연결. 기존 웹 체험 정책 유지 |
| 영상만 있고 자막·지문이 없으면 배정 자체가 불가능 | 자료 준비 완료를 재생 등록에도 요구 | 링크 재생용 등록과 파일 메타정보 등록 추가. 분석 미실행을 명시하고 근거 없는 내용 질문·요약은 차단 |
| Chrome이 읽는 파일도 선택 단계에서 거절 | MIME 종류로 선차단 | 파일 MIME·확장자 대신 Chrome의 실제 디코딩 결과로 판정. 실패하면 URL·이벤트를 정리하고 대안 안내 |
| 파일 재생에 실제 분석 업로드가 필요 | 파일 준비 경로가 실제 분석에 집중됨 | ‘로컬 파일 재생용 등록’은 이름·크기만 전송. 학생 기기에서 원본을 선택하며 원본을 읽어 서버로 전송하지 않음 |
| 연결·음성 목록 갱신 때 입력·초점이 흔들림 | 내부 중지 세대와 사용자 초점 세대의 혼동, 목록 갱신 시 저장값 강제 적용 | 정상 연결 초점 복귀와 새 입력 보존을 구분. 저장 전 선택한 음성도 유지 |

원본 탭 제어는 Chrome의 [프레임·문서 대상 스크립트 실행 API](https://developer.chrome.com/docs/extensions/reference/api/scripting)를 이용한다. 모든 사이트에 상시 권한을 부여하지 않으며 플레이어 탐색은 영상 상태와 필요한 iframe 출처만 확인한다.

## 사용 흐름

보호자는 링크를 등록하거나 ‘로컬 파일 재생용 등록’을 골라 파일을 선택하고 준비 결과에서 학생에게 배정한다. 자막·지문을 함께 넣으면 해당 자료도 처리한다. 분석하지 않은 영상의 내용을 분석했다고 표시하지 않는다.

학생은 링크의 ‘원본 강의 열고 연결’을 실행한다. 영상 제공자가 다른 출처라면 표시된 허용 버튼을 Enter로 실행한다. 파일은 ‘내 기기의 영상 연결·보관’에서 선택한다. 파일 등록에 원본 동기화용 해시가 없다면 수동 재생과 자료 읽기를 제공하며 자동 시점 해설을 연결하지 않는다. 분석한 원본의 해시가 있으면 다른 파일은 거부한다.

재생용 파일 등록·수동 재생에 앱의 100MB 제한을 적용하지 않는다. 브라우저 메모리와 디코더 한계는 남는다. 실제 분석 업로드와 선택형 암호화 보관의 기존 100MB 제한은 유지한다. 로컬 등록만으로 기기 간 원본 파일이 공유되지는 않는다.

한국어 음성 중 자연·신경망·고품질 음성을 우선 선택하며, 없으면 가용 음성으로 대체한다. 사용자가 명시한 음성·외부 스크린리더 모드는 보존한다. 사람이 듣는 자연스러움을 자동 검사가 인증하지는 않는다.

Space 1회 재생·정지, 2회 전체 중지, 3회 텍스트 명령, 3초 누르기 음성 명령을 유지한다. 기본 패널 열기는 Alt+Shift+S, 전체 중지는 Alt+Shift+X다. 음성 인식 첫 사용에는 동의와 Chrome 마이크 허용이 필요하다.

## 검증과 한계

검증 원본은 [동일 소스 통합 검사](verification/2026-11-15-universal/acceptance/results.json)와 [Chrome 연결 회귀 결과](verification/2026-11-15-universal/acceptance/universal/results.json)에 기록한다. 실제 설치한 확장·API·DB·디코딩 영상을 사용한다. iframe·열린 Shadow DOM의 실제 재생·중지, 빈 MIME 파일, 잘못된 원본 거부, 코덱 오류 정리, 초점 보존, 추가 출처 거절·재시도, 메타정보만 전송하는 배정을 검사한다.

최종 통합 검사 **10개 묶음 전부 통과**, 검사 전후 소스 지문 일치. `verify_all.sh`의 API는 **160 통과·4 건너뜀**이며 4개는 실제 PostgreSQL 환경이 필요한 검사다. 신규 Chrome 연결 회귀 **9개**, 기존 저장·복구 회귀 **17개**, 계정·편집 경합 회귀 **5개**도 통과했다. 검사 화면의 axe 위반은 **0건**이며 390px·1280px 캡처를 결과 폴더에 저장했다. 보호자 키보드 배정 흐름·문제 모드 차단·원본 미전송 기존 회귀도 포함한다. 기존 웹의 `student-design.css`, `role-portal.js`, `app.js` diff와 `docs/redesign/refs/` 상태 변경은 없다.

키보드 초점과 상태 알림의 전문 재검토는 [접근성 보고서](../.a11y-history/2026-11-15-universal/report.md)에 보관했다. 미해결 지적은 없으며 실제 보조기기 청취 검사와는 구분한다. 로컬 개발 패키지는 `dist/extensions/student`, `dist/extensions/guardian`, ZIP은 `dist/releases/0.4.7/`다. 기존 확장을 새로고침하고 열린 확장 탭·패널을 다시 열면 반영된다. 배포·스토어 게시는 하지 않았다.

네이티브 권한 창 완료와 패널 문맥 판정은 이 연결 회귀에서 명시적 시험 장치를 사용한다. iframe 주입은 시험 출처를 미리 허용한 실제 확장에서 실행하며 실제 사이드 패널 열기는 기존 운영 회귀에서 검사한다. 음성 합성·인식·분석 공급자의 서비스 경계도 시험 장치다. 이 결과를 실제 마이크 인식·음질·유료 분석 품질·모든 사이트 권한 창 통과로 확대하지 않는다.

‘Chrome에서 재생 가능한 모든 영상’도 사이트 로그인, DRM, 닫힌 Shadow DOM, 플레이어 API, 접근 권한, 실제 코덱에 따라 확장 제어가 제한될 수 있다. 보호된 스트림을 다운로드하거나 DRM을 우회하지 않는다. 일반 링크 등록은 서버의 기존 안전 URL 검사를 유지하므로 사설망·localhost 분석 URL은 허용하지 않는다. 링크 연결·파일 재생과 영상 내용의 실제 분석은 별개다. 내용 분석에는 준비된 자료 또는 명시적 동의와 설정된 분석 어댑터가 필요하다.

기존 웹 학생 화면·쿠키 인증·API 형식·Gemini 키·모델 설정은 유지한다. 기존 외부 검증 8개는 [기능 기준표](extension-feature-contract.json)에 남기며 자동 검사만으로 전체 실환경 완료를 선언하지 않는다.

## 추가 개발 후보

1. **플레이어 진단 화면**: 연결한 원본·영상 제공자 출처·권한·영상 인식·코덱·DRM 상태를 한곳에서 안내하고 재시도 버튼 제공. 원본이나 페이지 내용을 수집하지 않는 진단 내보내기.
2. **자료 없는 수강 보조**: 영상 위치에 메모·음성 북마크를 남기고, 나중에 자막을 추가하면 같은 시점과 연결. 실제 분석 여부를 계속 표시.
3. **동의 기반 사이트 어댑터**: 표준 HTML5 제어로 해결되지 않는 플레이어만 공개 API를 이용해 추가. 공통 연결 계약과 회귀 영상으로 검증하며 유료 강의 스크래핑은 제외.
4. **읽기 품질 빠른 설정**: 사용 가능한 한국어 음성 2~3개를 같은 문장으로 시험하고 속도·쉼을 저장. 별도 유료 음성 서비스 도입 전 기기 음성 품질부터 확인.
