# 기능 보존 재검사와 삭제 최적화 판정

이 문서는 0.4.4 검사 기록이다. 이후 원인 분석·F16 복원·검사 통합·코드 정리는 [0.4.5 조치](EXTENSION_RELIABILITY.md)와 [현재 기능 기준표](extension-feature-contract.json)를 참고한다.

2026-11-14 · 검사 대상: 현재 로컬 0.4.4, 기존 미커밋 변경 포함.

**전체 기능 누락이 없다고 확정할 수 없다. 따라서 사용자가 지정한 ‘누락 없음 확인 후 삭제’ 조건에 따라 이번에는 제품 코드·배포 설정·의존성을 삭제하지 않았다.** 자동 검사 통과와 원본 기능 전체 이전 완료를 구분한다.

## 기능 검사 결과

기존 78개 대응표를 현재 확장 소스와 대조하고, 전체 API·코어 검사와 설치한 두 확장의 누적 회귀를 다시 실행했다. 78개를 모두 실제 외부 서비스에서 독립 시험했다는 뜻은 아니다.

| 판정 | 수 |
| --- | ---: |
| 적용 확인 | 61 |
| 부분 적용 | 4 |
| 미적용 | 0 |
| 의도 변경 | 4 |
| 외부·실기기 검증 불가 | 7 |
| 기존 미지원 | 2 |

‘미적용 0’은 알려진 대응 항목에 구현 자체가 없는 경우가 없다는 의미다. **부분 적용·미검증까지 해소되었다는 뜻은 아니다.** 이전 0.4.4 결과도 전체 기능 보존 완료 판정이 아니었다.

| 남은 항목 | 이번 소스 대조 결과 |
| --- | --- |
| F16 보호자 준비 단계 대시보드 | 확장에 작업 건수·상태 필터·검색과 다음 행동 안내는 있다. 원본 `role-portal.js`의 학생·강의·배정·설정별 ‘완료/할 차례/아직/기본값’ 단계표는 동일하게 이전되지 않았다. |
| F23 분석 상세 진행 | 서버가 실제로 기록한 자료 등록·공급자 대기·안전 검증 상태는 제공한다. 공급자가 보고하지 않는 내부 음성·화면 분석 진행 정보는 제공하지 않는다. 추정 진행률을 만들어 완료로 판정하지 않았다. |

| F36 보호자→학생 원본 인계 | 별도 전달·학생 파일 선택·식별 대조는 제공한다. 분리된 확장 사이의 원본 자동 인계는 제공하지 않는다. 원본 자동 업로드를 추가해 보완하지 않았다. |

외부 확인 7개는 F24 실제 YouTube 분석, F25 업로드 영상 분석 품질, F26 외부 링크 분석기, F33 OS·코덱 조합, F49 실제 Gemini 대화, F61 VoiceOver/NVDA 전체 사용, F62 실제 마이크 인식 서비스다. 실제 유료 호출이나 사용자 DB를 사용하지 않았다.

## Render 관련 코드의 삭제 가능성

서비스 이름이 등장한다는 이유만으로 미사용 코드는 아니다. 현재 저장소에서 호출·설정·검사되는 경로를 확인했다. 현재 외부 배포가 가동 중인지 조회한 것은 아니다.

| 대상 | 확인한 의존 관계 | 판정 |
| --- | --- | --- |
| `render.yaml` | `DEPLOY_RENDER.md`에서 안내하는 기존 웹의 배포 설정. Gemini 모델 환경 설정도 포함한다. | 배포 지원 폐기와 기능 보존 확인 전 유지 |
| `Dockerfile`, `app/launch.py` | Render 설정과 CI의 `container` 작업이 사용한다. 웹·API 제공과 권한 하향·단일 워커 실행을 담당한다. | 공용 실행 경로이므로 유지 |
| `core/demo_gate.py`의 Render 조건 | 프록시 접속 IP 확인, 외부 DB 요구, 로컬 무제한 모드 차단에 사용된다. | 분석 사용량·비용 제한 경로이므로 유지 |
| `core/postgres_usage.py`, DB 마이그레이션, `psycopg` | `demo_gate`에서 직접 호출하며 CI의 PostgreSQL 작업과 관련 회귀가 검사한다. | 사용 중인 서버 기능이므로 유지 |
| `.env.example`, 배포 문서·관련 테스트 | 설정 방법과 기존 안전 동작을 보존한다. | 기능 코드와 함께 유지 |
| `neon.ts`, `@neon/config`, `@neon/env` | JS 구성 초안이며 Python 서버의 PostgreSQL 접속에는 쓰이지 않는다. 앱·빌드 스크립트에서 이 JS 도구를 호출하는 경로는 찾지 못했다. | 차후 정리 후보. 전체 삭제 조건이 미충족되어 이번에는 유지 |

`uvicorn`은 Render 전용 의존성이 아니다. 로컬 서버·확장 회귀 서버도 사용한다. `renderMaterial`, `renderPreparations` 같은 함수는 화면을 그리는 함수로, Render 배포 코드와 관련이 없다.

기존 [확장 개발 계획](EXTENSION_DEVELOPMENT_PLAN.md)은 미이전 기능을 기존 웹에 유지하고 모든 대응 항목을 검증한 뒤 웹 종료 여부를 결정하도록 한다. 현재 빌드도 공통 학습 기능을 기존 웹 소스에서 패키징하므로 웹 파일을 일괄 삭제할 수 없다.

## 다음 작업의 기준

먼저 F16의 단계별 안내를 보완하고 F23·F36의 현재 제한을 최종 지원 범위로 확정해야 한다. 실제 사이트·분석 공급자·보조기기 확인은 모의 검사로 대체하지 않는다. 이 결과로 기능 보존 범위를 확정한 뒤 미사용 Neon JS 도구부터 정리할 수 있다. Render·Docker·공용 DB 코드는 지원 종료 범위와 의존 관계를 함께 정리해야 한다.

이번 변경물은 재검사 결과와 이 보고서이며, 제품 코드나 데이터·원본 파일·배포 서비스는 변경하지 않았다.
