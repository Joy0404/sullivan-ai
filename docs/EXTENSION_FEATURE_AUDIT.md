# 원본 프로그램 기능 대비 확장 적용 검사

이 문서는 0.4.1 당시의 감사 기록이다. 이후 구현은 [0.4.2 기능 복원 결과](EXTENSION_FEATURE_RESTORATION.md), 최신 검증 판정은 [전체 기능 재검사 결과](EXTENSION_FULL_REAUDIT.md)를 참고한다.

검사일: 2026-11-13 · 대상: **현재 로컬 0.4.1 작업본**(아직 커밋하지 않은 수리 코드 포함).

**판정: 원본 기능 전체 이전은 완료되지 않았습니다.** 기본 테스트 통과와 기능 동등성은 다릅니다. 학생의 독립 학습과 접근성에 영향을 주는 누락이 남아 있어, 원본 기능 보존 완료 또는 출시 준비 완료로 판단하지 않습니다.

이번 작업은 검사입니다. 앱·서버 제품 코드를 추가 수정하거나 실제 사용자 계정 DB를 변경하지 않았습니다. 임시 DB·프로필·서버와 생성 MP4를 사용했고, 검사 스크립트·근거 파일·보고서를 추가했습니다.

## 기준과 판정 방법

- [원본 기능 설명서](../apps/web/manual/index.html): 2026-11-05 학생·보호자 전체 흐름.
- [원본 구현 상태표](FEATURE_STATUS.md)와 [통합 보고서](DEVELOP_학생_보호자_통합.md): 오래된 상태 표현은 현재 원본 소스와 대조.
- 원본 웹 소스는 `888a026` 기준과 차이가 없음을 확인. 확장 계획서를 구현 증거로 사용하지 않음.
- 최신 사용자 지시인 Space 1회 재생/정지·2회 전체 중지·3회 텍스트·3초 음성, 관리자 코드 제거는 이전 설명서보다 우선.
- 복합 기능을 아래 **78개 검사 항목**으로 나누었으며, 실제 사용자 기능 총수가 정확히 78개라는 뜻은 아님. 상태와 근거 범위를 함께 읽어야 함.

| 판정 | 항목 수 | 의미 |
| --- | ---: | --- |
| 적용 확인 | 37 | 주요 경로의 브라우저/API/코어 검사와 소스 연결을 확인. 실기기·외부 서비스 품질 보증 아님. |
| 부분 적용 | 17 | 구현 일부가 있거나 동등 동작/범위/검증이 부족. |
| 미적용 | 11 | 원본 UI/엔진/동작이 확장에서 누락되거나 실행 불일치 재현. |
| 의도 변경 | 4 | 분리 설계 또는 최신 명시 지시로 바뀐 동작; 통과/실패의 단순 분모에 넣지 않음. |

의도 변경과 원래 미지원 항목을 성공률의 분모에 넣지 않았습니다. 또한 적용 확인은 특정 시험 범위의 통과이며 모든 기기·실서비스의 무결함을 뜻하지 않습니다.

## 실제 실행 결과

- `verify_all.sh`: **API 150개 통과·4개 건너뜀**, 패키지 검사 3개, 기존 JS 기능·구문 검사 통과. PostgreSQL 실DB 검사 4개는 연결 환경이 없어 건너뜀.
- `verify_student_repair.py`: 실제 Chromium 156의 두 확장과 실제 사이드 패널·디코딩 영상에서 초기 회귀 통과. 중단 후 재실행 1회는 Space 3회 창 열기에서 실패해 안정성 미확정으로 기록. 음성 합성/인식과 공급자 응답은 시험 장치.
- `audit_extension_features.py`: 원본 동등성 프로브 **30개 중 19개 통과·11개 불일치**. 검사 완료를 통과로 숨기지 않고 `completed-with-parity-gaps`로 기록.
- 초기 수리 회귀 11개 화면과 최종 기능 감사 10개 화면에서 axe-core 4.14.0 WCAG A/AA 태그 검사 위반 0건. 이는 원래 기능 보존이나 실제 스크린리더 음성 검증을 의미하지 않음.
- 준비 작업 서버 프로세스 2회 재시작 및 운영 설정 시작/거부 검사 통과.

## 우선 보완해야 할 기능

| 우선순위 | 누락·불일치 | 학생/보호자에게 생기는 영향 |
| --- | --- | --- |
| 높음 | 홈에서 음성·타자·사용법 시작 불가 | 강의 선택 전에는 명령으로 첫 강의를 고르거나 사용법을 들을 수 없음 |
| 높음 | 초점 음성/외부 읽기 탐색 중 영상 정지 누락 | 강의 소리와 안내가 겹칠 수 있고, 원래의 안내 후 복귀·읽기 후 수동 재개 정책이 사라짐 |
| 높음 | Space 대기 중 Tab 이동이 명령을 취소하지 않음 | 다른 항목으로 이동했는데도 영상 재생이 뒤늦게 실행됨 |
| 높음 | 개념의 강사 구간→AI 설명 자동 연결 누락 | 개념 구간이 끝나도 설명으로 자동 전환하지 않음 |
| 중간 | 최초 안내·안내 완료·보호자 재안내 연결 누락 | 설정 화면의 안내 다시 표시가 학생에게 반영되지 않음 |
| 중간 | 배정 전 결과 미리보기 축소 | 보호자가 시각 설명·근거·개념·복습·대화를 충분히 검토할 UI가 없음 |
| 중간 | 강의 삭제 UI 누락 | 회수는 가능하나 원래처럼 강의 삭제를 실행할 수 없음 |
| 중간 | 답변 음성 독립 설정 불일치 | 답변 음성을 꺼도 초점 안내가 켜져 있으면 답변 음성이 요청됨 |
| 중간 | 복습 분류·탐색 원위치·텍스트 취소 복귀 축소 | 원래 학습 흐름의 일부 경로가 끊김 |
| 중간 | 원본 파일 인계·자연 음성 엔진 축소 | 학생이 파일을 따로 전달받아 재선택해야 하며 원래 자연 음성 처리 일부가 빠짐 |

원본 파일의 자동 인계는 서로 다른 확장 출처를 사용하는 구조에서 단순 복사로 복원하면 안 됩니다. 원본 웹도 다른 기기에 자동 전달하지 않았습니다. 명시적 전달·수신 확인과 원본 식별, 또는 수동 전달 안내를 설계해야 합니다.

추가 소스 차이로 준비 차임, 입력칸의 설명 중 긴급 중지, 펼침/pressed/current 상태 음성, 상세 도움말, 우선 분석 모드 선택, 단계별 분석 진행 표시도 기록했습니다. 이는 자동 접근성 검사에서 위반 0건이어도 존재할 수 있는 기능 차이입니다.

재실행 실패 근거: [Space 3회 회귀 실패 기록](verification/extension-feature-audit-retry.json). 신규 기능 프로브와 별도 시도이며, 이후 감사 실행이 완료돼도 이 실패를 통과로 덮어쓰지 않습니다.

## 검증하지 못한 경계

실제 VoiceOver/NVDA의 설치·로그인·권한·학습 낭독, 사람이 듣는 한국어 음성 품질, 실제 마이크와 Chrome 인식 서비스, 실제 Gemini의 정확도/비용/지연, 실제 YouTube·유료 강의 사이트·교차 출처 플레이어, OS/코덱별 파일 재생은 이번 검사의 합격 범위에 포함하지 않았습니다. 시험 인식기가 명령을 전달한 결과를 실제 음성 인식 성공으로 표시하지 않습니다.

“현재 화면 다시 설명”은 원본과 확장 모두 가까운 시점의 준비된 안전 설명을 선택하는 기능입니다. 새 화면을 촬영·분석하는 기능이 원래 동작했다고 간주하지 않습니다. DRM 우회와 복잡한 도형 완전 해설도 원본에서 미지원/범위 밖이었습니다.

## 재현과 검토 자료

브라우저 검사 의존성은 `scripts/requirements-extension-tests.txt`, Chromium 설치가 필요합니다. 시험 MP4용 ffmpeg 또는 imageio-ffmpeg가 필요합니다. axe를 함께 실행하려면 `SULLIVAN_AXE_SOURCE`에 설치한 `axe.min.js`를 지정합니다.

```bash
PATH="$PWD/.venv/bin:$PATH" bash scripts/verify_all.sh
.venv/bin/python scripts/audit_extension_features.py
.venv/bin/python scripts/verify_preparation_restart.py
.venv/bin/python scripts/verify_extension_production.py
```
