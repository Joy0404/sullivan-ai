# 확장 누락 기능 복원 결과

**후속 판정:** 2026-11-14 전체 재검사에서 경합·초점·안내 문제를 확인했다. 현재 출시 판정과 갱신한 기능 상태는 [전체 기능 재검사 결과](EXTENSION_FULL_REAUDIT.md)를 기준으로 한다. 아래 내용은 구현 직후의 기록이다.

2026-11-13 · 로컬 버전 **0.4.2**. 기존 감사에서 미적용으로 분류한 11개 항목의 구현을 추가했다. 원본 프로그램 전체의 출시 검증이 끝났다는 뜻은 아니다. 기존 웹 소스·학생 디자인·Gemini 모델 설정은 수정하지 않았다. 아직 커밋·업로드·스토어 배포하지 않았다.

이전의 [0.4.1 감사](EXTENSION_FEATURE_AUDIT.md)와 실패 관찰값은 보존한다. 갱신한 [78개 항목 목록](verification/extension-feature-restoration-inventory.json)은 적용 확인 59, 부분 적용 6, 미적용 0, 의도 변경 4, 외부 검증 불가 7, 기존 미지원 2다. 적용 확인은 기록된 검사 범위의 결과다.

삭제는 해당 강의의 배정과 학생 학습 기록을 함께 삭제한다. 준비 결과와 기기의 원본 파일은 유지한다. 삭제 전 화면에서 이 범위를 확인한다.

정답 보호와 신뢰도 0.72 미만 보류 규칙은 유지한다. 학생이 선택한 영상은 서버로 업로드하지 않는다. 보호자의 원본 분석과 결과 질문에는 각각 동의가 필요하다. 관리자·초대·분석 이용 코드는 다시 추가하지 않았다.

## 실제 검사와 한계

- `PATH="$PWD/.venv/bin:$PATH" bash scripts/verify_all.sh`: API **152개 통과·4개 건너뜀**, 패키지 검사 3개, 기존 JS·구문·안전 검사 통과. PostgreSQL 실DB 검사는 환경이 없어 건너뜀.
- `verify_feature_restoration.py`: 실제 Chromium 156에 두 확장을 설치하고 실제 사이드 패널·디코딩 MP4·보호자 질문 UI·가입/연결/복구·키보드·취소·원본 검증·삭제 흐름 검사. [브라우저 결과](verification/extension-feature-restoration-results.json).
- axe-core 4.14.0으로 390px·1280px 화면을 확인한 14개 상태에서 WCAG A/AA 태그 위반 0건. 스크린샷은 `docs/verification/extension-*.png`에 저장한다.
- `test_student_core.mjs`: 오래된 음성 완료·겹친 안내·문장 사이 중지·읽기 모드·연결 실패와 편집/홈 키 이벤트를 검사. 패키지 검사에서 자연 음성 선택과 발음·문장 분리도 확인한다.
- 준비 서버의 실제 프로세스 재시작 2회와 운영 설정의 시작·거부 검사 통과. 키보드·모달·상태 안내·ARIA·미디어·폼 소스 전문 검토의 미해결 지적은 0건. [접근성 검토 보고서](../.a11y-history/2026-11-13-feature-restoration/report.md).

자동 검사에서 음성 합성·인식과 Gemini 응답은 시험 장치다. 실제 VoiceOver/NVDA 낭독, 마이크 인식 서비스, 사람이 듣는 한국어 음질, 실제 Gemini 결과 품질과 YouTube/유료 강의 사이트 호환은 별도 확인이 필요하다.

계속 부분 적용으로 남긴 항목은 F16(원본의 세부 대시보드), F23(공급자 내부 단계 진행 정보), F34(실제 사이트 호환), F36(확장 사이 원본 자동 인계), F44(강조 데이터가 있는 자료의 전체 실사용 검증), F56(오프라인 저장 실패·복구 전 과정)다. 내부 진행률을 추정해 표시하거나 원본 자동 전달이 되는 것처럼 표시하지 않는다.

## 로컬 적용

현재 빌드: `dist/extensions/student`, `dist/extensions/guardian`. ZIP: `dist/releases/0.4.2/`. 로컬 서버 `http://127.0.0.1:8770`용이며 스토어 게시물은 아니다.

```bash
cd /Users/joy/Documents/Codex/Sullivan-AI-Develop-local
.venv/bin/python scripts/build_extensions.py
.venv/bin/python scripts/package_extensions.py
bash START_LOCAL.command --restart --sample --no-open
```

Chrome의 `chrome://extensions`에서 **학생용·보호자용 모두 새로고침**하고 버전 0.4.2를 확인한 뒤 기존 패널과 확장 탭을 닫아 다시 연다. 읽기 방식에서 앱 음성 안내 또는 외부 스크린리더를 선택한다. `--sample` 서버는 실제 Gemini 분석을 실행하지 않는다. 실제 분석 설정은 기존 로컬 실행 안내를 따른다.

브라우저 회귀 검사:

```bash
SULLIVAN_AXE_SOURCE=/path/to/axe.min.js \
  .venv/bin/python scripts/verify_feature_restoration.py
```

필요 패키지는 `scripts/requirements-extension-tests.txt`, Chromium은 `python -m playwright install chromium`으로 설치한다. CI도 이 복원 회귀 검사를 실행하도록 연결했다.
