# 확장 추가 점검·수정과 다음 개발 제안

2026-11-14 · 로컬 개발 버전 **0.4.4**. 이전 미커밋 작업을 이어서 수정했다. 기존 웹 화면·학생 CSS·쿠키 인증·Gemini 설정은 수정하지 않았다. 스토어 게시와 운영 배포는 하지 않았다.

후속 [기능 보존·삭제 최적화 재검사](EXTENSION_CLEANUP_AUDIT.md): 미적용 0과 전체 이전 완료는 다르다. 부분 적용 4개·외부 미검증 7개가 남아 있어, ‘누락 없음 확인 후 삭제’ 조건의 배포 코드 정리는 진행하지 않았다.

## 추가로 확인하고 수정한 동작

| 문제 또는 누락 | 반영한 동작 |
| --- | --- |
| 메모 자동 저장이나 홈 명령에서 직접 입력한 학습 위치가 빠짐 | 저장 경로가 아직 입력 중인 위치도 검증·반영한다. 영상이 연결돼 있으면 명시적인 위치 저장 전까지 입력값을 재생 위치로 덮지 않는다. |
| 북마크·밑줄 저장 실패 뒤 강의 전환으로 기록을 잃음 | 메모·위치 외에 북마크·밑줄의 미저장 상태도 추적한다. 이전 기록을 저장하지 못하면 현재 강의를 유지한다. |
| 수동 위치 저장 실패 때 입력 상태를 먼저 지움 | 서버 저장 성공 전에는 입력 상태를 지우지 않는다. 새 입력이 응답 도중 들어오면 이전 응답으로 지우지 않는다. |
| 자동 저장 실패를 앱 음성으로 알리지 않고 재시도 경로가 불분명함 | 실패 이유·재시도 방법과 ‘학습 기록 다시 저장’ 버튼을 제공한다. 자동 실패는 처음 한 번, 복구는 한 번 안내하고 명시 재시도 결과는 매번 알린다. 성공 뒤 재시도 버튼에 있던 초점은 기본 저장 버튼으로 복원한다. |
| 로그아웃 전 대기열에 있던 저장이 나중에 실행될 수 있음 | 실제 전송 직전에도 계정 화면 세대와 강의를 확인하고 오래된 대기 저장을 취소한다. |
| 보호자 준비 작업을 상태별로 모아 찾기 어려움 | 접수·진행·완료·실패·중단 건수, 상태 필터, 제목·과목 검색, 결과 수와 마지막 서버 상태 갱신 시각을 추가했다. 공급자 진행률을 추정하지 않는다. |
| 목록 갱신으로 준비 작업 버튼이 사라질 때 초점 유실 | 같은 작업, 인접한 작업, 목록 제목 순으로 초점을 복원한다. 검색·필터에 있는 초점은 유지한다. |

이전 작업에 있던 긴 지문 정규화 재사용과 저장 오류 시 영상 연결 보존도 검증했다. 600문장 시험 자료의 문단 명령에서 정규화 추가 호출은 **0회**, 측정 시간은 해당 실행의 [최적화 결과](verification/2026-11-14-followup/optimization/results.json)에 남겼다. 이는 한 시험 환경의 관찰이며 모든 자료에 대한 성능 보장은 아니다.

## 검증 근거

- `verify_all.sh`: **API 153 통과·4 건너뜀**, 패키지 검사 3개, JS 코어·구문·정적 검사 통과. PostgreSQL 실DB 4개는 환경 부재로 건너뛰었다. [실행 로그](verification/2026-11-14-followup/verify-all.log).
- 추가 브라우저 회귀 **17개 통과**: 위치·북마크·밑줄·실패·복구·앱 음성 경계·로그아웃 대기 저장·검색·상태·초점·키보드 배정. [결과](verification/2026-11-14-followup/results.json).
- 기존 확정 문제 **R01–R18 전부 통과**, 보조 기능 관찰 30개도 통과. [결과](verification/2026-11-14-followup/reaudit/results.json).
- 기존 누적 복원 검사 통과: 두 실제 확장, 계정·연결·배정·원본 식별·영상 재생·Space·질문·복습·저장. [결과](verification/extension-feature-restoration-results.json).
- 최적화 경계 4개 통과: 긴 지문 재사용, 강의 전환 시 위치 저장, 저장 실패에도 영상 연결 유지, 실패 안내. [결과](verification/2026-11-14-followup/optimization/results.json).
- 추가 검사 7개 화면 상태의 axe-core WCAG A/AA 태그 위반 **0건**. 390px·1280px 캡처와 초점을 확인했다. [보호자 검색 화면](verification/2026-11-14-followup/extension-guardian-preparation-dashboard-viewport-390.png), [학생 재저장 화면](verification/2026-11-14-followup/extension-student-save-recovery-viewport-1280.png).
- 보호자 **학생 만들기 → 사전 준비 샘플 선택 → 배정** 구간을 실제 키보드 이벤트로 완료했고 포인터 이벤트는 0회였다. macOS headless Chromium에서 기본 선택 상자 방향키가 반영되지 않아, 학생 선택은 영문 시험 이름의 기본 typeahead, 샘플은 기본 과학 샘플을 사용했다. 실제 한국어 이름 탐색과 보조기기 사용은 별도 실사용 확인이 필요하다.
- 키보드·상태 안내 전문 소스 재검토에서 미해결 지적 0건. [접근성 보고서](../.a11y-history/2026-11-14-followup/report.md).

임시 DB·프로필·서버를 사용했다. 저장 503, 작업 목록의 진행 상태, 음성 합성은 명시적인 시험 경계다. 원본 영상의 실제 디코딩과 학생 업로드 미전송은 기존 누적 검사에 포함된다. 실제 VoiceOver/NVDA 낭독, 마이크 인식 서비스, 한국어 음질, YouTube·강의 사이트 호환, 실제 유료 분석 품질을 확인했다고 주장하지 않는다.

수정 전 재현 8개는 [before 결과](verification/2026-11-14-followup/before/results.json)에 보존했다. 중간 검사에서 발견한 성공 안내 위치 변경과 고정 버전 문자열 기대는 현재 UI·버전 계약에 맞게 바꾸었고, 오프라인 복구 검사는 실제 DB 메모 확인까지 강화했다. 키보드 검사 초기 실패는 [기록](verification/2026-11-14-followup/results-keyboard-first.json)에 남겼다. 기존 검사의 최초 불일치도 [기록](verification/2026-11-14-followup/reaudit-first-result.json)에 보존했다.

## 남은 범위와 추가 개발 아이디어

아래는 **제안이며 이번에 구현한 기능이 아니다.** 현재 구현과 실사용 미검증 항목을 구분해 진행한다.

| 우선순위 | 제안 | 기대 효과와 완료 기준 |
| --- | --- | --- |
| 1 | 미저장 기록의 선택형 임시 보관·복구 | 지금은 화면을 닫으면 미저장 기록을 잃을 수 있다. 계정·강의별 암호화 초안을 명시적으로 켜고 보관 기간·삭제를 선택하게 한다. 재로그인 및 현재 배정 확인 후 복원하고, 서버 기록과 다르면 덮어쓰기 전에 비교한다. 원본 영상 보관과는 별개다. |
| 1 | 강의 연결·음성 진단 화면 | 영상 없음, 주소 변경, 광고·실시간 구간, 코덱 미지원, 마이크 거부, 음성 없음의 실제 원인을 모아 다음 행동을 안내한다. 실제 지원 사이트·OS·VoiceOver/NVDA 조합을 시험해 지원 목록을 명시한다. |
| 2 | 학습 근거 타임라인 | 자막·검증된 설명·개념·북마크를 시점별로 함께 찾고 ‘이미 들은 내용’은 조용한 색인으로 제공한다. 각 설명의 판단 이유를 바로 열 수 있게 하며 HOLD 후보와 문제 모드 정답은 목록·검색·내보내기에서도 제외한다. |
| 2 | 배정 전 준비 점검과 원본 전달 확인 | 보호자가 자료 준비·문제 보호·학생 배정·원본 별도 전달 여부를 확인하고, 학생은 원본 식별 일치 여부를 확인한다. 원본을 서버에 자동 업로드하거나 자동 전달한다고 표시하지 않는다. |
| 2 | 여러 학습 화면의 기록 충돌 감지 | 현재 재생 소유권과 별도로, 다른 화면에서 먼저 저장한 메모·북마크를 감지해 마지막 요청이 조용히 덮지 않게 한다. 기록 버전과 충돌 복구 UI를 새 확장 API로 설계한다. |

공급자 내부 진행률, 실제 사이트별 동작, 확장 사이 원본 자동 인계는 이 대시보드 추가로 완료된 것이 아니다. 기존 78개 기능 목록 전체를 이번 17개 검사로 다시 인증하지 않는다.

## 적용과 재현

현재 생성물은 `dist/extensions/student`, `dist/extensions/guardian`과 `dist/releases/0.4.4/`다. Chrome에서 **두 확장을 새로고침하고 열려 있던 확장 탭·학생 패널을 닫아 다시 연다.** 서버 프로토콜은 유지되며, 서버 버전 표시는 기존 로컬 서버를 재시작하면 갱신된다.

```bash
PATH="$PWD/.venv/bin:$PATH" bash scripts/verify_all.sh
SULLIVAN_AXE_SOURCE=/path/to/axe.min.js .venv/bin/python scripts/verify_extension_followup.py
.venv/bin/python scripts/build_extensions.py
.venv/bin/python scripts/package_extensions.py
```

브라우저 의존성은 `scripts/requirements-extension-tests.txt`와 Chromium이다. 최적화·누적 미디어 검사는 ffmpeg도 사용한다. CI에 추가 회귀와 최적화 검사를 연결했다.
