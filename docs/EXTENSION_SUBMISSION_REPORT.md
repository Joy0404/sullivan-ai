# 0.4.9 판서 보류·분석 상태·제출 검증

2026-11-15, 로컬 `main`의 확장 분리 작업. 설치 절차는 [제출본 설치 안내](SUBMISSION_INSTALL.md)에 있다. 아래 구현과 자동 검증은 실제 유료 Gemini 실행, 실제 스크린리더 낭독 및 모든 강의 사이트에서의 재생 품질을 증명하지 않는다.

## 수정 내용

- `visual_gap.py`는 숫자·연산자·부등호·단위·변수 결합과 수식 순서를 먼저 비교한다. 판서 `2x + 1 = 7`과 현재 발화 `2x + 1 = 8`은 일반 문자 유사도만으로 `INDEX_ONLY`가 되지 않는다. 같은 정보를 말한 경우는 복습용으로 유지한다. 이전 발화와 현재 발화를 섞어 중요한 차이를 숨기지 않는다.
- 한국어 수식 읽기를 수식 문맥 안에서 정규화한다. `이 엑스 더하기 일은 칠입니다`는 `2x + 1 = 7`과 같아 `INDEX_ONLY`, `팔입니다`는 실제 값이 달라 자동 해설한다. 일반 문장의 수사나 지원하지 않는 띄어 쓴 수·소수의 일부분을 같은 수식으로 오인하지 않도록 회귀를 추가했다.
- 실제 분석의 두 단계 판독에서 부분별 확신도·화면 근거·불일치를 확인한다. 두 판독은 같은 장면을 비교하는 절차이며 독립된 진실 자료가 아니다. 강조 문장은 원문 근거를 확인한다. 후보 숫자·단위·문구는 공개 결과에 들어가지 않는다.
- 확인된 부분은 정상 설명하고, 불확실한 부분은 `‘세로축의 단위’ 부분은 확실치 않아서 설명을 보류하겠습니다.`처럼 허용된 위치 문구를 같은 해설에 붙인다. 전체 판독 불가일 때는 `‘이 장면의 판서’ 부분은 확실치 않아서 설명을 보류하겠습니다.`를 안내한다. 원래 관찰의 `HOLD`·확신도·비공개 정책은 유지하며 안전한 위치 안내만 별도로 전달한다.
- 확신도 0.72 미만, 문제 모드 정답의 차단을 유지한다. API·복습·지문·개념·음성 경로를 함께 검사한다. 다른 불확실한 부분에 같은 숫자가 있다는 이유로 확인된 부분까지 지워지지 않도록 부분별 출처를 사용한다.
- 강의 출처 이름과 분석 상태를 분리한다. 서버의 처리 기록에 따라 `Gemini 분석 중/완료/실패`, `사전 준비 샘플`, `영상 분석 미실행`, `분석 상태 확인 불가`를 표시한다. 직접 입력한 출처 이름·가져온 JSON은 Gemini 완료 기록을 만들 수 없다. 재생용 링크·자막·지문 등록은 영상 분석 미실행이며, 기록이 없는 기존 강의는 상태 확인 불가다.
- 보호자 결과 로딩 중 다른 입력란으로 이동한 경우 초점을 보존하고 완료 상태만 알린다. 진행 중인 해설은 초점 안내로 잘리지 않는다. 외부 스크린리더 모드는 앱 합성을 끄고 한 해설 영역으로 전달한다. 합성 실패는 연결 실패와 구분하고 안전한 읽기 본문·일시정지를 유지한다.
- Space 제스처·누름 횟수·3초 기준은 변경하지 않았다. 기존 웹 학생 CSS·학생 함수·인증 흐름은 수정하지 않았다. 이전 0.4.8 보호자 로그인 지원도 포함한다.

## 공개 시연과 실제 분석의 구분

`accessibility` 사전 준비 샘플은 직접 만든 23초 영상과 JSON·SRT·TXT로 구성한다. `samples/public-manifest.json`에 출처·공개 이용 조건을, 제출본 `SUBMISSION_MANIFEST.json`에 파일별 무결성을 기록한다.

1. 처음에는 강사가 판서와 같은 `2x + 1 = 7`을 말하므로 자동 해설 없이 지난다.
2. 다음에는 판서는 7이고 발화는 8이므로 확인된 판서를 설명한다.
3. 증가하는 그래프는 설명하고 흐린 세로축 단위만 지정 문장으로 보류한다.
4. 판서 전체가 흐린 장면은 전체 보류 문장만 안내한다.

이 샘플은 제출 시 새로 영상 분석한 결과가 아니다. Gemini 키를 끄고 보호자가 배정하고 학생이 로컬 MP4를 연결하는 경로를 검증한다. 학생 원본은 API로 보내지 않는다. 실제 분석 경로의 회귀 검사는 명시적인 HTTP 공급자 시험 응답을 사용하며 실제 Gemini 완료 증거와 구분한다.

## 검증 결과와 한계

초기 통합 자동 검사 기록은 `docs/verification/2026-11-15-submission/acceptance/results.json`과 각 하위 로그·JSON에 저장한다. 판서 비교·부분/전체 보류·정답 차단·서버 상태·확장 인증·보호자 로그인 지원·기존 재생·키보드·파일 보관·390/1280 화면·axe를 포함한다. `scripts/verify_all.sh`와 `scripts/verify_extensions.py`가 최종 판정 명령이다.

한국어 수식 추가 수정 전 통합 검사는 동일한 소스 지문에서 12개 검사 묶음이 모두 통과했다. API 247개 통과·4개 미실행(격리 Postgres 시험 DB 미설정), 패키지 검사 15개 통과이며 Node 회귀 검사도 통과했다. 새 시연 흐름 9개를 통과했고 기록된 axe 위반은 0이다. 390/1280 화면은 같은 검증 폴더에 보관한다.

한국어 수식 비교 수정 후 `scripts/verify_all.sh`를 다시 실행해 API **270개 통과·4개 미실행**(격리 Postgres 시험 DB 미설정), 패키지 검사 **15개 통과**, Node 회귀 통과를 확인했다. 정확한 칠·팔 비교는 실제 결정 함수와 `LectureAgent.analyze` 경로에서 검사했다. 이 추가 수정의 증거는 `docs/verification/2026-11-15-korean-math/`에 있으며, 이전 12개 브라우저 검사 결과와 소스 지문을 혼동하지 않는다. 제출 ZIP을 최신 소스와 회귀 검사로 재생성했다.

접근성 소스 검토는 keyboard-navigator, live-region-controller, aria-specialist로 수행했고 발견한 문제를 수정한 뒤 재검토했다. 해당 범위의 미해결 지적은 없으며 보고서는 `.a11y-history/2026-11-15-submission/`에 있다. 자동 axe 결과와 소스 검토는 실제 보조기술 사용자 검증을 대체하지 않는다.

미검증 항목:

- 실제 Gemini 키를 사용한 신규 영상 분석·결과 품질: 키가 없는 환경에서 실행하지 않았다. HTTP 시험 응답을 사용한 경로 회귀만 수행했다.
- VoiceOver·NVDA 등 실제 스크린리더의 낭독·읽기 순서·중복 체감: 실기 미검증이다.
- 사람이 직접 들은 앱 음질과 음성 출력: 미검증이다. 브라우저 네이티브 음성 엔진 신호는 `native-tts-probe.json`에 별도 기록한다. 개별 실행 round10에서는 시작·종료 각 1회가 관찰됐으나 통합 headless 실행에서는 확인하지 못했다. 합성 객체를 교체하지 않은 별도 깨끗한 네이티브 세션에서는 초기 제출 ZIP에서 추출한 코드로 부분 보류를 포함한 해설 전체의 시작·종료를 확인했다(`native-clean/results.json`). 사람의 청취 결과를 뜻하지 않는다. 제어된 합성 시험의 텍스트 전달 결과와 구분한다.
- 외부 강의 사이트·DRM·모든 OS/코덱 조합: 전체 완료 판정을 하지 않는다. Chrome 지원 형식 및 접근 허용 범위 안에서 동작한다.

## 제출물
