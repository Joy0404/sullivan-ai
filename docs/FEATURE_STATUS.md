# 구현 상태

발표에서 `동작`, `재현 데모`, `연결 필요`를 구분한다.

| 기능 | 상태 | 설명 |
| --- | --- | --- |
| MP4/WebM/MOV/M4V 선택·재생 | 동작 | 브라우저 로컬 URL로 재생 |
| 업로드 영상 직접 음성 전사·화면/OCR 분석 | 조건부 동작 | 별도 원본 전송 동의와 `GEMINI_API_KEY`가 있을 때 Files API로 임시 전송, Gemini 2단계 분석 뒤 삭제 요청 |
| 공개 MP4/WebM 링크 재생 | 동작 | 브라우저가 원격 주소를 직접 재생, API는 영상 미다운로드 |
| YouTube 링크 재생 | 동작 | 개인정보 보호 강화 임베드 재생 |
| YouTube 링크 AI 분석 | 조건부 동작 | `GEMINI_API_KEY` 설정 시 Gemini가 장면을 자율 탐색하고 별도 Gemini 시각 근거 단계가 다시 검증 |
| 분석 진행 화면 | 동작 | 링크·음성·화면·교차검증·가이드 생성 단계를 완료 전까지 표시 |
| YouTube 재생-해설 동기화 | 동작 | IFrame Player API의 실제 재생시간과 시점 통과 이력을 0.2초 간격으로 감지 |
| 실시간 Pause→해설→Resume | 동작 | 버퍼링·짧은 지연을 허용하며 중요 시각정보 시점에 자동 정지, TTS 후 재생 |
| 자연스러운 한국어 TTS | 조건부 동작 | Natural·Neural·Online 우선, 미리 듣기, 음색·말투·음높이·음량·속도와 문장별 호흡·종결 억양 조절 |
| 맥락형 화면 해설 | 동작 | 현재 맥락 1문장→화면 핵심→다음 연결 1문장, 앞뒤 문장 길이 제한 |
| 요약 음성 가이드 | 동작 | 분석된 발화·시각정보·강조 내용을 한국어 음성으로 안내 |
| AI 학습 대화 | 동작 | 강의 근거로 주제 설명·비교·흐름·원인/전개/결과·암기표·계획·퀴즈·발표문 생성 |
| 학습 대화 음성 입력·출력 | 조건부 동작 | Web Speech API 지원 브라우저에서 요청을 인식하고 결과를 TTS로 안내 |
| Space 전역 음성 제어 | 조건부 동작 | 2초 누르면 명령 목록 안내 후 두 번째 알림음과 함께 인식, 키를 떼면 한 번 실행; 1초 안에 두 번 누르면 음성 중지·강의 복귀 |
| 기타 링크 AI 분석 | 조건부 동작 | `LINK_ANALYZER_URL` 설정 시 표준 분석 패키지를 검증해 반영 |
| SRT/VTT 처리 | 동작 | 타임코드·태그 정리 후 전사 타임라인 생성 |
| TXT/MD 지문 처리 | 동작 | 문단·문장·의미 흐름 구조화 |
| 분석 JSON 처리 | 동작 | 표준 계약 검증 후 에이전트 실행 |
| 강사 발화-화면 비교 | 동작 | 시간창과 토큰 중복률 사용 |
| 판서 부호·숫자 변화 | 동작 | 이전 화면과 문자열 차이를 설명 |
| 모델 기반 개입 선택 | 조건부 동작 | Gemini가 앞뒤 발화와 실제 프레임을 보고 5가지 행동을 제안하고 안전 계층이 재검증 |
| Pause → TTS → Resume | 동작 | 브라우저 영상과 Speech Synthesis 연동 |
| 핵심 개념 탐색 | 동작 | 강사 핵심 키워드·흐름 색인, 검색, 강사 구간→AI 재설명, 즉시 중지 |
| 핵심 탐색 음성 명령 | 조건부 동작 | Web Speech API 지원 브라우저에서 동작 |
| Accessible Lesson Review | 동작 | 발화·시각정보·강조·타임스탬프 연결 |
| 낮은 확신도·근거 없는 관측 비공개 | 동작 | 확신도 0.72 미만 또는 별도 시각 근거 없는 Gemini 후보를 HOLD |
| 개인정보 비공개 처리 | 동작 | 이메일·한국 휴대전화·주민등록번호 형태를 공개 출력 전에 치환 |
| 문제 정답 차단 | 동작 | 문제 보호 모드에서만 `answer` 관측 HOLD, 일반 모드는 검증된 정보 제공 |
| 과학·역사 샘플 | 재현 데모 | 두 공개 영상의 사전 준비 데이터를 화면에 샘플로 명시 |
| 복잡한 도형 완전 해설 | 범위 밖 | 후속 연구·사용자 검증 필요 |
| DRM 강의 다운로드 | 미지원 | 의도적으로 구현하지 않음 |

## 기술 부채

- 메모리 저장소를 사용자별 영속 저장소로 교체
- 실제 모델 결과의 보정·비용·속도·중단된 대용량 업로드 재시도
- OCR/STT 정확도와 Visual Gap 정답셋 평가
- 브라우저별 한국어 TTS 음질 비교와 사용자 선호 저장
- 실제 시각장애 학생과의 사용성 테스트
