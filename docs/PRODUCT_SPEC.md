# 제품 정의 — Internet Lecture Accessibility Agent

## 한 문장

Sullivan AI는 인터넷 강의를 단순히 읽거나 요약하는 AI가 아니라, 강사가 말하지 않고 화면으로만 전달한 정보를 찾아 설명하고 긴 판서와 지문을 비시각적으로 탐색하게 하는 학습 에이전트다.

## 해결하는 문제

강사가 식을 화면에만 추가하거나, `+3`을 `-3`으로 고치거나, 긴 지문의 한 문장에 밑줄을 긋고 “여기가 중요합니다”라고 말하면 음성만 듣는 학생에게는 정보의 대상이 사라진다. 문제는 영상을 들을 수 있느냐가 아니라 **눈으로 훑고, 찾고, 돌아가고, 강조 위치를 확인하는 학습 행동에 접근할 수 있느냐**다.

## 대상과 사용 조건

- 주 사용자: 인터넷 강의를 이용하는 시각장애 및 저시력 중·고등학생
- 입력: 사용자가 이용 권한을 가진 영상, 학교·교사가 제공한 녹화물, 공개 교육 영상, 자막과 지문
- 제외: 실시간 교실 촬영, DRM 우회, 자동 강의 다운로드, 무단 복제, 문제 정답 생성

## SDG 4 연결

SDG 4는 포용적이고 형평성 있는 양질의 교육을 요구한다. Sullivan AI의 `Learning Parity`는 장애로 생긴 정보 장벽을 제거하되 다른 학생이 수행하는 사고 과정을 AI가 대신하지 않는다. 문제 모드에서 정답을 차단하는 이유는 기능 부족이 아니라 **접근성과 학습 형평성을 동시에 지키는 설계**이기 때문이다.

## 핵심 기능

### Visual Gap Detection

같은 시간대의 강사 발화 토큰과 화면 관측 토큰을 비교한다. 화면의 중요 정보가 발화에서 충분히 확인되지 않으면 화면 유형·종류·중요도에 따라 행동을 선택한다.

| 조건 | 행동 |
| --- | --- |
| 미발화 핵심 수식·숫자·조건 | 즉시 `INTERRUPT` |
| 중요 그래프·긴 추가 판서 | `DESCRIBE_AT_BREAK` |
| 강사가 이미 충분히 설명 | `INDEX_ONLY` |
| 확신도 72% 미만·문제 정답 | 내용 비공개 `HOLD` |
| 장식·낮은 중요도 | `SKIP` |

### Context-Aware Playback Control

`INTERRUPT` 시 영상 재생 상태를 기억하고 일시정지한다. 검증된 설명만 자연스러운 한국어 TTS로 읽은 뒤 이전에 재생 중이었다면 자동으로 재생한다.

### Semantic Passage Reconstruction

지문을 문단과 문장으로 나누고 `문제 제기`, `주장 전개`, `반론·대조`, `필자의 결론`, `정리` 흐름을 표시한다. 밑줄·강조와 영상 시점을 문장에 연결한다.

### Non-Visual Random Access

학생은 텍스트 또는 음성으로 다음을 요청할 수 있다.

- 밑줄·강조 문장
- 앞 문장 / 다음 문장 / 앞뒤 문장
- 현재 문단 / 3문단
- 반론 부분 / 필자의 결론
- 특정 단어가 들어간 문장

### Accessible Lesson Review

강의 후 핵심 발화, 화면으로만 제시된 정보, 강조 문장, 다시 볼 타임스탬프를 하나의 접근 가능한 복습 화면으로 만든다.

## 성공 지표

- Visual Gap Precision / Recall
- 불필요한 영상 중단 비율
- 강조 문장 위치 정확도
- 탐색 명령 성공률
- 요청부터 음성 출력까지의 지연
- 복습 항목과 원 영상 시점의 추적 가능성

## 대회용 완성 기준

API 키 없이 판서와 지문 시나리오가 항상 동일하게 재현되고, 업로드한 SRT/VTT/TXT/MD가 실제 처리되며, 외부 모델이 없을 때는 결과를 꾸며내지 않고 연결 필요 상태로 남는다. 발표에서는 이 세 상태를 섞지 않는다.
