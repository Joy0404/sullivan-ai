# 2026-11-16 기능 검사 후속 수정

현재 로컬 작업본에서 확인한 오류를 수정했다. 이전 검사 결과는 [수정 전 보고서](verification/2026-11-16-project-audit/REPORT.md)에 보존한다. 실제 사용자 DB·서비스·운영 배포·스토어는 변경하지 않았다.

## 제품 수정

- **계정·강의 간 메모 복사 경합:** 필기 시작·수정·복사·내보내기가 비동기 작업을 기다린 뒤에도 시작한 계정·강의·편집 상태가 같은지 검사한다. 취소는 호출자의 후속 저장까지 중단한다. 초안 키도 시작한 계정·강의로 고정한다.
- **복사 중 추가 입력 유실:** 충돌 초안 복사가 영상 정지 응답을 기다리는 동안 새 글을 입력하면 이전 복사를 취소한다. 새 글과 원래 초안은 유지하고 명시적 재시도에서 최신 본문을 새 필기로 보존한다.
- **저장 실패의 복구 경로:** 저장 실패로 강의 전환을 막았으면 기존 기록이 있는 필기 화면과 재시도 버튼을 노출한다. 잘못된 위치 값은 설정 화면의 해당 입력란으로 안내한다. 그동안 다른 작업에서 입력을 시작했다면 초점을 빼앗지 않고 전역 오류 영역에서 복구 경로를 알린다.
- **같은 작업의 음성 명령:** 내용 찾기 안에서 문단 명령을 실행할 때 기존 선택 조작의 초점을 유지한다. 다른 작업에서 진입하면 내용 찾기 제목으로 이동한다.
- **간헐적인 샘플 분석 상태 유실:** 개인정보 필터가 무작위 세션 ID 속 숫자를 전화번호·주민등록번호처럼 해석해 ID를 바꾸고, 원래 ID로 저장한 분석 상태를 찾지 못하는 문제를 확인했다. 내부 참조 ID는 보존하고 표시 본문·파일 이름·설명에는 개인정보 가리기를 유지한다. 전화번호·주민등록번호 모양의 고정 ID 두 사례는 수정 전 실패·수정 후 통과를 검사한다.

수정한 제품 코드는 학생 확장의 `app.js`, `notes.js`와 API의 `local_access.py`다. 기존 웹 학생 CSS·학생 함수·웹 인증·API 계약·Gemini 호출 설정은 유지한다.

## 검증

**최종 종합 검증 15개 묶음이 모두 통과했다.** [acceptance-final/results.json](verification/2026-11-16-audit-fixes/acceptance-final/results.json)의 `result=passed`, `source_unchanged=true`로 같은 소스 지문에서 실행했음을 확인했다.

- `bash scripts/verify_all.sh` 통과: API **283개 통과·4개 건너뜀**, 제출 패키지 pytest **15개 통과**, 확장 빌드 경계 unittest **3개 통과**, Node 구문·기능 검사 통과. 기존 테스트를 삭제하지 않고 식별자 회귀 2개를 추가했다.
- 건너뛴 4개는 격리 PostgreSQL 시험 DB 미설정에 따른 기존 항목이다. 기존 Starlette/anyio 폐기 예정 경고 1개가 있다.
- 학생 필기·새 필기 경합·보호자 대시보드·저장 복구·요청 경합·원격 로그인·보호자 진입·제출 흐름·범용 플레이어·누적 기능 복원·18개 재검사·성능/저장·실제 프로세스 재시작·운영 설정 검사가 모두 통과했다.
- 기록된 axe 검사 위반 0건이며 390px·1280px 캡처를 저장했다. 보호자 키보드 전용 학생 생성→샘플→배정도 통과했다.
- `apps/web/student-design.css`, `apps/web/app.js`, `apps/web/role-portal.js` diff가 없고 레퍼런스 이미지의 Git 상태 변화가 없다. `git diff --check` 통과.
