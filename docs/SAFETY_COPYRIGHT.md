# 안전·개인정보·저작권 원칙

## 콘텐츠 이용

Sullivan AI는 사용자가 이용·분석할 권한이 있는 영상과 자료를 전제로 한다. 유료 강의의 DRM을 우회하거나 보호된 스트림을 다운로드하는 기능은 없으며 추가해서도 안 된다. 접근성 목적이 모든 복제·전송을 자동으로 허용한다는 뜻은 아니므로 실제 서비스에서는 국가별 법률과 콘텐츠 이용약관을 별도로 검토해야 한다.

권장 입력은 다음과 같다.

- 사용자가 직접 제작하거나 적법하게 보유한 영상 파일
- 학교 또는 교사가 제공한 녹화물
- 공개 라이선스 교육 영상
- 플랫폼이 허용하는 범위에서 확보한 자막·보조자료

## 원본 영상 최소화

기본값에서 웹은 영상을 브라우저 객체 URL로만 재생하고 API에 바이너리를 전송하지 않는다. 사용자가 로컬 영상의 실제 AI 분석을 별도 체크한 경우에만 원본을 임시 전송한다. API의 로컬 임시 파일은 분석 성공·실패와 관계없이 즉시 삭제하고, Gemini Files API의 원격 파일도 분석 직후 삭제 요청한다. 삭제 요청이 실패하면 공급자 정책에 따라 최대 48시간 뒤 자동 삭제될 수 있음을 화면에 미리 고지한다. API 키와 원본 바이너리는 세션·응답·강의 보관함에 기록하지 않는다.

## 개인정보 공개 최소화

자막, 지문, 화면 관측, 학습 노트처럼 사용자에게 다시 노출될 수 있는 텍스트에서 이메일, 한국 휴대전화 번호, 주민등록번호 형태를 공개 전에 비공개 문자열로 치환한다. 치환된 값만 복습·TTS·학습 대화에 사용한다. 이는 흔한 형식을 막는 기본 방어선이며, 운영 서비스에서는 별도의 DLP 점검과 사용자별 삭제 정책이 추가로 필요하다.

## 불확실 정보

OCR 확신도가 72% 미만이면 후보 문자열을 학생 출력, TTS, 복습, `source_text`에서 제거한다. 사용자가 “현재 화면 해설”을 눌러도 `safe_to_speak`가 거짓인 관측은 선택되지 않는다.

## 학습 형평성

문제 모드의 정답 화면은 접근성 해설 대상이 아니다. 문제 조건과 일반 학생이 볼 수 있는 탐색 단서는 제공하되 정답을 생성하거나 공개하지 않는다. 이는 시각장애 학생에게 정보를 덜 주기 위한 규칙이 아니라, 다른 학생과 같은 문제 해결 기회를 주기 위한 규칙이다.

## 운영 전 추가 사항

- 학생 계정과 보호자·학교 정책
- 개인정보 처리방침과 삭제 요청
- 공급자 데이터 학습 제외 계약
- 저작권자·플랫폼 약관 검토
- 보안 점검, 비밀키 관리, 감사 로그
- 실제 사용자를 포함한 접근성·오류 피해 평가
# 링크 영상 처리 원칙

- 사용자가 이용·분석 권한을 확인하지 않으면 링크를 등록하지 않는다.
- API는 영상 링크를 직접 다운로드하거나 로그인·쿠키·DRM을 우회하지 않는다.
- localhost, 사설망, 링크 로컬 주소는 차단해 SSRF 경로로 사용되지 않게 한다.
- 공개 YouTube 링크는 사용자가 설정한 Gemini API 키가 있을 때만 Google Gemini 영상 분석 API에 전달한다.
- 기타 외부 분석기는 명시적으로 설정된 `LINK_ANALYZER_URL`만 호출하며 임시 원본 삭제를 요청한다.
- 분석기가 없거나 실패하면 `분석 완료`로 표시하지 않고 안전하게 중단한다.
