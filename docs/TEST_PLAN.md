# 테스트 계획

## 자동 테스트

- 재생시간이 자동 해설 시점을 정상 통과했을 때 대상 선택
- 5초 이내의 폴링·버퍼링 지연 뒤에도 놓친 해설 회수
- 큰 탐색 점프에서는 지나간 해설을 갑자기 읽지 않음
- `INDEX_ONLY`, `HOLD`, 이미 안내한 항목은 자동 해설 대상에서 제외
- 핵심 개념의 별칭·범주 검색과 강사 구간 타임스탬프 연결
- 강사 구간→AI 재설명 중지 시 영상과 음성이 함께 멈춤
- 모든 자동 해설 구간에 짧은 사전 맥락과 사후 연결 문장이 준비됨
- 맥락 문장 길이와 전체 문장 수가 제한을 넘지 않음

`apps/api/tests`는 다음을 검사한다.

- 말하지 않은 핵심 수식의 `INTERRUPT`
- 강사가 이미 말한 정보의 `INDEX_ONLY`
- 72% 미만 관측의 후보 비공개
- `+3 → -3` 부호 변화 설명
- 문제 모드 정답 차단
- 지문 문단·문장·강조·의미 흐름 구조화
- 강조·다음 문장·결론 탐색
- SRT/VTT 타임코드 파싱
- 영상 자산의 `local-only` 상태
- 로컬 원본 전송 별도 동의가 없을 때 분석 요청 차단
- 동의한 업로드 영상이 분석 중에만 임시 파일로 존재하고 완료 뒤 삭제되는지 확인
- 업로드 영상의 실제 전사·화면 관측 결과가 같은 2단계 안전 경로에 색인되는지 확인
- 샘플 분석부터 접근성 복습까지 전체 코어 흐름
- API 생성·분석·탐색·404
- 실제 어댑터 미설정 시 실패 차단

실행:

```bash
cd apps/api
python -m pytest -q
```

## 수동 접근성 확인

1. 마우스 없이 Tab·Shift+Tab·Enter로 모든 기능을 실행한다.
2. 패널 전환 시 제목으로 초점이 이동하는지 확인한다.
3. 화면 해설과 음성 명령 상태가 라이브 영역에 전달되는지 확인한다.
4. Space를 2초간 눌렀을 때만 알림음·인식 상태가 시작되고, 키를 떼기 전에는 명령이 실행되지 않는지 확인한다.
5. 입력칸에서 Space를 짧게 누르면 공백이 입력되고, 길게 누르면 전역 음성 명령으로 전환되는지 확인한다.
6. `prefers-reduced-motion`에서 녹음 애니메이션이 멈추는지 확인한다.
7. 한국어 음성이 없는 환경에서도 텍스트 설명이 유지되는지 확인한다.
8. 모바일 360px 폭에서 가로 스크롤 없이 핵심 동작이 가능한지 확인한다.

## 운영 전 평가

실제 사용자 데이터셋에서 Visual Gap precision/recall, 화면 해설 환각률, 두 단계 검증의 수정·삭제 비율, 불필요한 중단 비율, 문장 위치 정확도, 명령 성공률, 응답 지연과 복습 추적성을 별도로 측정해야 한다. 자동 테스트 통과를 실제 모델 정확도로 해석하지 않는다.
