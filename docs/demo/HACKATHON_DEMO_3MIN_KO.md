# Sullivan AI 최신 버전 시연 시나리오·대본

목표 **2분 50초(170초)**. 제목·엔딩·앱 음성·명령 대기까지 포함하며, 3분 제한에 10초 여유를 둔다. 실제 녹화 시간은 리허설로 확인한다. 최신 main의 전역 Space 단축키와 ‘영상 중지’ 명령을 기준으로 작성했다. 이 문서는 촬영안이며 녹화·제출 완료 보고가 아니다.

핵심 메시지: **말로 전달되지 않은 화면 정보를 보완하고, 학생이 직접 멈추고 찾아보며 강의로 돌아오게 한다.**

## 촬영 전 준비

1. `bash START_LOCAL.command --sample --no-open`으로 실행하고 [소개](http://127.0.0.1:8770/intro/)와 [앱](http://127.0.0.1:8770/)을 연다.
2. 촬영용 보호자·학생 계정을 준비하고, 학생에게 과학 샘플 한 개를 배정해 둔다. 로그인·비밀번호 입력·최초 사용법 확인은 녹화 전에 마친다. 학생 목록의 첫 강의가 시연할 강의인지 확인한다.
3. 보호자·학생 창은 쿠키가 분리된 브라우저 프로필로 준비한다. 같은 프로필의 두 탭에서 서로 다른 계정으로 로그인하지 않는다.
4. 학생 강의를 0:40 부근에 멈추고 저장 상태를 확인한다. 과학 샘플 첫 자동 해설 지점은 0:43이다. 자동 정지·해설을 켜고, 앱 버튼 이름 음성은 촬영 중 중복되지 않도록 조절한다.
5. 마이크와 앱 소리가 모두 녹음되는지 짧게 시험한다. 음성 인식이 허용되는 환경인지 확인하고, 실제 명령을 말할 때 발표자의 설명은 멈춘다. 앱 낭독도 4~6초만 들려준 뒤 중지한다.
6. OBS 장면은 ‘소개 / 보호자 준비실 / 학생 학습’ 세 개로 구성한다. 브라우저 창 크기는 맞추고 개인 알림을 끈다. 화면 녹화에는 제출에 사용할 수 있는 자료와 촬영용 계정을 쓴다.

## 시간별 시나리오와 대본

아래 **내레이션**만 읽는다. **실제 명령**은 Space를 누른 채 앱에 말하는 내용이며, 앞뒤 설명과 겹치지 않는다.

## 조작 큐카드

- **Space 길게 누른 채 말하기 → 떼기:** 음성 명령. 학생 홈·수강 화면의 입력칸 밖에서 사용한다. 빠른 명령 영역으로 초점을 옮길 필요가 없다.
- **Space 두 번:** 영상·세 줄 요약 등 앱 음성 즉시 중지. 설명 중에는 입력칸에서도 중지할 수 있다. 운영체제 스크린리더 자체의 낭독 제어와는 구분한다.
- **Space 세 번:** 타자 명령. 입력 후 Enter로 실행한다. 입력창의 일반 Space는 띄어쓰기다.
- **버튼에서 한 번:** 연속 입력을 기다린 뒤 선택한다. 버튼을 즉시 선택하려면 Enter를 쓴다.
- 녹화 명령 순서: `1번 강의 열어줘` → `영상 재생` → `세 줄 요약` → **두 번 눌러 중지** → `요약 멈추고 강의로 돌아와` → `영상 중지`.

## 녹화 중 대체·편집 기준

- 마이크를 사용할 수 없으면 Space 세 번으로 **동일한 문구를 타자 입력**한다. 이 컷의 대사는 “음성 명령을 쓰기 어려우면 같은 명령을 타자로 입력합니다.”로 바꾼다. 음성 인식이 성공한 것처럼 편집하지 않는다.
- 자동 정지 컷을 재현하지 못하면 ‘현재 화면 다시 설명’을 직접 실행하고 “필요할 때 현재 화면 해설을 다시 들을 수 있습니다.”로 대사·자막을 맞춘다.
- 앱 음성을 끝까지 기다리지 않는다. 요약·문단은 4~6초만 들려주고 **실제 Space 두 번으로 중지한 결과**를 담는다. 강의 복귀 후 재생과 ‘영상 중지’ 후 정지 상태도 각각 짧게 보여준다.
- 영상이 길어지면 보호자 준비실 소개와 문단 듣기 시간을 줄인다. **샘플 고지 / 요약 낭독·두 번 중지 / 강의 복귀·영상 중지**는 남긴다.
- 완성본은 제목·장면 전환·엔딩을 포함해 3분 이내인지 확인한다. 발표자와 앱 음성이 겹치지 않고, 샘플 표시를 읽을 수 있어야 한다.
