# Sullivan AI 3분 이내 프로젝트 시연안

2026-11-17 로컬 소스 기준. 학생·보호자 Chrome 확장으로 촬영한다. 목표 길이는 제목·앱 음성·전환·엔딩을 포함한 **2분 50초**다. 실제 길이는 리허설에서 확인한다.

핵심 메시지: **말로 전달되지 않은 화면 정보를 보완하고, 학생이 직접 찾아 듣고 필기하며 학습을 이어가게 한다.**

## 소개할 기능

| 기능 | 보여줄 내용 | 전달할 가치 |
| --- | --- | --- |
| 보호자 준비·배정 | 사전 준비 샘플을 학생에게 배정 | 보호자가 준비하고 학생이 자기 화면에서 수강 |
| 사용법·상태·키보드 명령 | 현재 상태, 도움말, Space 세 번으로 타자 명령 | 조작과 현재 상황을 학생이 직접 확인 |
| 시점에 맞춘 화면 해설 | 연결된 영상의 자동 정지·준비된 해설·재개 | 화면에만 있는 판서와 구조를 음성으로 보완 |
| 내용 찾기 | 문단 듣기, 개념 검색, 연결 시각 | 긴 자료를 필요한 단위로 다시 탐색 |
| 학생 개인 필기 | 선택 문장에 필기, 자동 저장, 연결 원문 확인 | 학생 자신의 생각과 원문을 함께 보존 |
| 짧은 요약·전체 중지 | 요약 일부 듣기, Space 두 번으로 중지 | 설명을 듣고 멈추는 시점을 학생이 결정 |
| 학습 보호·공유 범위 | 엔딩 자막으로 설명 | 낮은 확신도 관측과 문제 모드의 정답 관측 차단, 필기 본문 비공유 |

실제 영상 분석과 새로운 강의 질문 답변은 공급자 설정·동의·응답 대기가 있으므로 이번 기본 촬영 동선에서 제외한다. 샘플의 준비된 설명과 요약을 새 영상 분석 또는 실시간 화면 인식이라고 소개하지 않는다.

## 촬영 전 준비

1. 현재 서버와 두 확장의 버전을 맞추고, 촬영용 보호자·학생 계정으로 미리 로그인한다. 가입·비밀번호·권한 허용 과정은 촬영 전에 마친다.
2. 보호자 확장에는 학생과 과학 샘플을 준비한다. 배정 버튼만 실제로 실행할 수 있도록 배정 직전 화면을 준비하거나, 이미 배정된 결과를 보여준다. 결과 화면만 보여줄 때 새로 배정한 것처럼 표현하지 않는다.
3. 학생 확장은 해당 샘플과 원본 영상의 연결, 음성 재생, 자동 해설을 리허설한다. 현재 `build_demo_package()`의 주요 판서 관측 시점은 **3:55**이므로 3:52 부근에서 시작할 수 있다. 기존 저장 자료나 다른 샘플이면 실제 해설 시점을 먼저 확인한다. 샘플 영상·자료의 일치도 확인한다.
4. `주계열성` 검색 결과와 첫 문단 듣기, 선택 문장에 필기·원문 확인을 미리 시험한다. 필기 예시는 `수소 핵융합이 시작되면 주계열성.`이다.
5. 화면은 원본 강의와 학생 사이드 패널이 함께 보이게 배치한다. 작은 글자는 해당 패널을 확대해 편집한다. Tab 초점 테두리와 상태 문구가 보이게 한다.
6. 마이크와 앱 소리를 함께 시험 녹음한다. 앱 음성 구간에는 발표자가 말하지 않는다. 실제 명령·재생·정지와 결과를 붙여 보여준다.
7. 샘플 장면에는 `사전 준비된 샘플 결과 · 새 영상 분석 아님` 자막을 유지한다.

| --- | --- | --- |
| 0:00–0:15 | 강의 화면과 학생 패널, 서비스 이름 | 문제와 제품 목적 소개 |
| 0:15–0:35 | 보호자 확장 → 과학 샘플 배정 또는 배정 결과 | 샘플 고지, 역할 분리 |
| 0:35–0:55 | 학생 강의 목록 → 도움말/현재 상태를 짧게 표시 → Space 세 번 → `1번 강의 열어줘` 입력·실행 | 화면에 맞는 키보드 안내. 시연 강의를 목록 첫 번째로 준비 |
| 0:55–1:25 | 연결된 과학 영상 3:52 부근에서 재생 → 3:55 해설 지점 통과 → 자동 정지·해설·재개 | 앱 음성 5~7초는 내레이션 없이 들려준다. 설명이 길면 다른 컷에서 중지·재개 결과까지 담는다 |
| 1:25–1:50 | 내용 찾기 → 첫 문단 듣기 3~4초 → 전체 중지 → `주계열성` 검색 → 결과 시각 표시 | 긴 지문과 개념 탐색을 한 장면으로 연결 |
| 1:50–2:15 | 내용 찾기의 문장 선택 → 선택 문장에 필기 → 한 줄 작성 → 저장 상태 → 연결 원문 확인 | 학생이 직접 입력하는 과정과 저장 완료 표시 |
| 2:15–2:30 | 강의 듣기 → 짧은 요약 듣기 → 3~4초 후 Space 두 번 | 요약 음성이 실제로 멎는 결과를 보여준다 |
| 2:30–2:50 | 필기 저장 결과 또는 설정·관리 화면 위에 보호 원칙 자막 → 서비스명 | 안전과 학생의 학습 주도권으로 마무리 |

## 읽을 대본

대괄호는 조작 지시이며 읽지 않는다. 각 시간은 말뿐 아니라 조작·앱 소리·전환을 포함한다.

**0:00–0:15**

“강의에서 ‘이 그림을 보세요’라는 말만으로는 화면 속 내용을 알기 어렵습니다. 설리번 AI는 시각장애 학생이 화면 정보를 듣고, 스스로 학습을 이어가도록 돕습니다.”

**0:15–0:35**

“지금은 사전 준비된 샘플로 시연합니다. 새 영상을 분석하는 장면은 아닙니다. 보호자는 강의를 준비해 배정하고, 학생은 별도의 학습 화면에서 수강합니다.”

**0:35–0:55**

“학생은 키보드로 조작합니다. 현재 상태와 도움말을 확인할 수 있고, 스페이스를 세 번 누르면 타자 명령을 입력할 수 있습니다.”

[Space 세 번 → `1번 강의 열어줘` → Enter. 명령은 내레이션으로 읽지 않아도 된다.]

**0:55–1:25**

“준비된 자료에서 화면 정보가 필요한 시점에 도달하면 강의를 잠시 멈추고 설명합니다. 판서의 화살표와 수치처럼 말만으로 놓치기 쉬운 정보를 보완합니다.”

[자동 정지 → 앱 해설 5~7초 듣기. 이때 말하지 않는다. 재개 결과도 담는다.]

**1:25–1:50**

“긴 지문은 문단이나 문장 단위로 다시 들을 수 있습니다.”

[문단 음성 3~4초 → 전체 중지.]

“찾고 싶은 개념을 검색하면 관련 내용과 강의 시각을 함께 확인할 수 있습니다.”

[`주계열성` 검색 결과와 연결 시각을 보여준다.]

**1:50–2:15**

“이해한 내용은 학생이 직접 필기합니다. 선택한 원문에 연결해 작성하면 자동으로 저장되고, 나중에 원문을 다시 확인할 수 있습니다. 필기 본문은 보호자나 AI 공급자에게 보내지 않습니다.”

[`수소 핵융합이 시작되면 주계열성.` 입력 → 저장 확인 → 연결 원문 확인.]

**2:15–2:30**

“핵심 요약도 들을 수 있습니다. 스페이스를 두 번 누르면 영상과 앱 음성을 모두 멈춥니다.”

[짧은 요약 3~4초 듣기 → Space 두 번 → 중지 확인.]

**2:30–2:50**

“확신이 낮은 화면 관측은 공개하지 않고, 문제 보호 모드에서는 정답 관측을 차단합니다. 필요한 정보에 접근하고, 자기 생각을 남기며, 자기 속도로 배우도록 돕는 설리번 AI입니다.”

## 자막·실패 대체

- 시작·샘플 구간: `사전 준비된 샘플 결과 · 새 영상 분석 아님`
- 해설 구간: `준비된 해설을 재생 시점에 맞춰 안내`
- 필기 구간: `학생 직접 작성 · 자동 저장 · 연결 원문 확인`
- 엔딩: `학생이 스스로 이어가는 학습`
- 자동 해설을 재현하지 못하면 **현재 시점의 준비된 설명**을 직접 누르고 대사를 “필요할 때 현재 시점에 준비된 설명을 다시 들을 수 있습니다”로 바꾼다. 이를 자동 정지로 소개하지 않는다.
- 타자 창이 열리지 않으면 **타자 명령 창 열기** 버튼을 사용하고 해당 컷에서 세 번 누르기에 성공했다고 표현하지 않는다.
- 음성이 재생되지 않으면 실제 화면 텍스트를 보여주고 “음성으로 안내됩니다”라는 성공 장면은 따로 촬영한다. 외부 스크린리더 검증을 완료했다고 주장하지 않는다.
- 시간이 넘으면 상태/도움말 표시와 검색 결과 체류 시간을 줄인다. 샘플 고지와 실제 해설·필기·중지 결과는 유지한다.
- 녹화 후 제목·장면 전환·엔딩을 포함해 3분 이내인지 확인한다. 이 문서의 2분 50초는 촬영 목표이며 실측 길이가 아니다.
