# 전체 기능 검사 및 코드 최적화

로컬에서 재현한 오류 10건을 수정했다. 수정 후 API·JavaScript·설치 확장·기존 웹 검사는 통과했다. 실제 공급자와 보조기기가 필요한 기능은 검증 대기이며, 제품 전체에 오류가 없다고 단정하지 않는다. 기존 미커밋 변경과 이전 검증 자료·개인 DB를 보존했고 커밋·푸시·운영 배포는 하지 않았다.

## 수정한 오류

| 재현된 문제 | 수정과 회귀 검증 |
| --- | --- |
| 준비 당시 문제 모드가 꺼진 강의를 학생 설정으로 보호하면 정답이 자막·모델 문맥에 남음 | 원문 후보를 지우기 전에 공통 snapshot 안전 필터가 차단 원문을 수집하게 했다. 학생 API·원문 선택·모델 입력에서 정답이 제거되는지 검사했다. |
| 내용 찾기에서 외부 스크린리더 읽기 결과가 숨겨진 듣기 영역으로 전달됨 | 하나의 기존 live region을 작업 공통 영역으로 이동했다. 선택 문장·문단의 실제 접근성 트리 노출, 초점 유지, 앱 TTS 미호출, 다시 진입할 때 이전 결과 제거를 검사했다. 기존 로그아웃·강의 전환의 초기화 경로도 소스에서 확인했다. |
| 삭제 응답이나 기기 정리가 늦으면 다른 계정·강의·새 필기 편집기를 지움 | 시작한 초안 키를 사용하고 비동기 경계에서 범위를 재확인한다. 삭제한 이전 항목만 제거하고 다른 편집기·커서를 보존한다. 실제 API 삭제 응답을 지연한 설치 확장 검사도 추가했다. |
| 자동 저장과 명시적 저장이 겹치면 같은 버전으로 다른 본문을 전송함 | 기기 초안 보존부터 서버 저장까지 하나의 진행 작업으로 직렬화한다. 새 입력은 다음 버전으로 저장하고, 같은 본문은 중복 요청하지 않는다. |
| 오래된 원문 조회가 새로 작성 중인 필기를 빈 연결 필기로 바꿈 | 원문 조회 전의 편집 세대가 같은 경우에만 연결 필기를 시작한다. |
| 저장 후 초안 정리를 기다리는 중 새로 입력한 복구 상태가 지워질 수 있음 | 새 본문·dirty 상태를 다시 확인하고 시작한 계정·강의에 재보존한다. 계정 전환 후에도 새 초안을 보존하는 결정적 검사를 추가했다. 네이티브 Chrome 저장 순서의 실제 역전을 관찰했다는 뜻은 아니다. |
| 필기 999개에서 동시 생성하면 1001개가 저장됨 | 삽입과 같은 쓰기 트랜잭션 안에서 1000개 한도를 재검사한다. 동시 요청의 결과가 200/413이고 총 1000개인지 검사했다. |
| 버전 확인 직후 다른 수정이 끼면 삭제 0행인데 성공으로 응답함 | 버전 확인·삭제를 같은 쓰기 잠금 안에서 처리하고 삭제 행 수를 확인한다. 실제로 지우지 못한 요청은 409로 응답한다. |
| 같은 학생을 중복 배정하는 수정 요청이 DB 예외로 500을 반환함 | 기존 배정 변경 전에 중복을 거부한다. 제목·배정이 그대로 보존되는지 검사했다. |
| 빈 질문·잘못된 재생 시각·깨진 JSON이 500을 반환함 | 기존 인증·공급자 확인 순서를 보존하고 입력 오류를 422로 응답한다. 공급자 미호출을 검사했다. |

서버 유효 요청·응답 형식, 인증, Gemini 키·모델·호출 설정은 유지했다. 기존 웹 학생 CSS·함수도 변경하지 않았다. 제출본 모델 경로는 계속 `baseline`이다.

## 측정한 최적화

필기 내보내기는 연결된 필기마다 강의 전체를 다시 읽고 정리했다. 이제 한 내보내기 요청 안에서 현재 권한으로 공개 가능한 원문을 한 번 읽고 ID·종류·원문 지문으로 조회한다. 요청 사이에 원문을 캐시하지 않으며, 다음 요청에서 배정 철회·저확신도·문제 모드 변경을 다시 확인한다. 중복된 snapshot 정리 코드도 공통 안전 필터로 통합했다.

생성한 필기 200개, 같은 임시 DB·강의·현재 권한 검사, 각 경로 3회 HTTP 요청의 비교다. 기존 내보내기 코드는 `cf5fabe`에서 읽어 같은 현재 권한·안전 경계와 함께 실행했다. 내보낸 응답 바이트는 모두 동일했다. GitHub에서 재현할 때는 동일한 필기 원본 코드가 있는 `3795880`을 기준으로 사용한다. 두 기준의 `student_notes.py`가 바이트 단위로 같은 것을 확인했으며, 기존 측정 JSON의 실제 기준 기록은 보존한다.

| 항목 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 강의 snapshot 조회/요청 | 200회 | 1회 |
| 처리 시간 중앙값 | 283.86ms | 4.85ms |
| 동일 본문의 겹치는 저장 | PUT 2회 | PUT 1회 |

시간은 이 기기의 생성 자료에 대한 로컬 결과다. 실제 사용자 강의의 처리 시간이나 Gemini 토큰 절감률로 일반화하지 않는다. [측정 원자료](note-export-benchmark.json)와 [재현 도구](../../../scripts/benchmark_note_export.py)를 제공한다.

```bash
.venv/bin/python scripts/benchmark_note_export.py --baseline-ref 3795880 \
  --output /private/tmp/sullivan-export-benchmark.json
```

## 전체 검증 결과

- `bash scripts/verify_all.sh` 통과: API **360 통과·4 제외**, 제출 패키지 **15 통과**, 확장 빌드 경계·Node 구문/기능 검사 통과. 시작 시 API는 351 통과였으며 9건을 추가하고 기존 검사를 제거하지 않았다.
- 확장 종합 검사 **15/15 묶음 통과**: 학생 필기·경합, 보호자 대시보드·진입, 저장 실패 복구, 요청 경합, 원격 로그인, 시연 흐름, 범용 플레이어, 기능 복원, 재감사, 성능/저장, 실제 서버 프로세스 재시작, 운영 설정을 포함한다.
- 기존 웹 **7/7 묶음 통과**: 역할별 전체 흐름, 키보드, 학생 진입, 음성 설정, 음성·재생, 보호자 세션, 로그인 시작.
- 수정한 필기 비동기 동작 7가지의 결정적 Node 검사를 기본 검증 명령에 추가했다. 신규 스크린리더 결과 노출과 삭제 응답 경합은 실제 설치 Chromium에서도 검사했다.
- 확장 종합 결과의 axe 4.14.0 검사 기록 **107건, 위반 0건**. 보호자 키보드 전용 학생 생성→샘플→배정과 1280px·390px 화면 캡처를 보존했다. [axe 근거 목록](axe-summary.json).
- 학생 원본 미디어 API 전송은 검사 범위에서 0건이다. 안전 후보·정답 차단의 API/복습/모델 입력 회귀 검사도 통과했다. 데모와 모의 공급자 결과는 실제 모델 분석으로 표시하지 않았다.
- 실제 종합 검사는 개인 DB와 이전 검증 자료를 제외한 격리 복사본에서 수행했다. 수정 후 원본과 복사본의 소스 지문이 같고, 검사 중 소스가 바뀌지 않았음을 확인했다. API 테스트 파일도 원본과 대조했다.

최종 근거: [검증 요약 JSON](results.json), [전체 검증 로그](verify-all.log), [확장 종합 결과](extensions/full-acceptance/results.json), [기존 웹 결과](web/results.json), [전문 검토 및 조치](specialist-review.md).

`dist/extensions`의 학생·보호자 로컬 빌드를 현재 소스에서 다시 만들고 기존 서버 주소를 보존했다. [빌드 대조 결과](local-build.json). 실행 중 서버·Chrome 확장과 기존 제출 ZIP은 자동 교체하지 않았다. 사용 중인 서버를 재시작하고 Chrome 확장을 새로고침한 뒤 확장 화면을 다시 열어 적용한다.

## 미검증 범위

별도 PostgreSQL 시험 DB가 필요한 기존 검사 4건은 제외됐다. 실제 Gemini 영상 분석·질문 품질·재시도 포함 토큰, 외부 분석기와 비정상 종료 시 공급자 원본 삭제, 실제 YouTube·유료 강의 사이트·권한창·OS/코덱 조합, 마이크·브라우저 음성 인식, 사람이 듣는 한국어 TTS, VoiceOver/NVDA 전체 낭독은 미검증이다. 기능 기준표의 외부 검증 대기 8항목과 `release_ready=false`를 유지했다.

원본·권한이 있는 강의와 실제 공급자·보조기기를 사용한 검증이 끝나기 전에는 이 로컬 통과를 실환경 전체 정상 또는 출시 완료로 해석하지 않는다.
