## 구현한 내용

[기획안 v2.2](../../FEEDBACK_DEVELOPMENT_PLAN_V2_2026-11-16.md)의 10개 절과 역할 분리·독립 수강 목표를 유지했다. 우선 구현 범위를 호출 없는 시작 안내와 기존 조작 연습으로 좁혔다.

- 보호자: 짧은 첫 시작 안내와 선택형 상세 설명서, 가입→학생 동의·연결→샘플 배정 안내를 추가했다. 안내 버튼은 실제 기존 입력 위치로 이동하며 초안을 보존한다. 연결·샘플 배정 상태는 받은 서버 목록과 확인 시각으로 표시한다. 코드를 만들었다고 연결 완료로 표시하거나 학생 기기의 재생을 확인했다고 주장하지 않는다.
- 학생: 위쪽에 **현재 상태**, **도움말**을 고정하고 기존 버튼·Space·타자·허용한 음성 경로를 재사용했다. 안내를 한꺼번에 길게 읽는 대신 핵심 조작을 짧게 안내한다.
- 학생 실습: 이미 배정된 **사전 준비 샘플**과 연결된 영상에서 Space 재생 후 일시정지→전체 중지→타자 창에서 현재 상태 실행을 직접 확인한다. 영상 미연결·샘플 미배정은 실습 완료로 계산하지 않는다. 선택형 음성 연습, 다시 하기·나중에 하기, 계정·버전별 기기 진도를 제공한다.
- 명령 확인: 고정된 기능 이름과 듣기·해석·처리·완료·실패·취소 상태를 사용한다. 질문·필기·인식 원문을 최근 명령 표시나 연습 저장소에 넣지 않는다. 이전 계정·강의·실습의 늦은 응답과 중복 음성 종료 이벤트를 차단한다.
- 효율: 안내·현재 상태·도움말·조작·준비된 설명은 생성 요청을 추가하지 않는다. 같은 계정·강의·처리 세대에서 동일 질문이 진행 중이면 기존 요청을 공유한다. 질문 결과를 계정 간 캐시하거나 새 분석을 시작하지 않는다.

기존 웹 학생 CSS·학생 함수·쿠키 인증·API 계약·Gemini 키/모델 설정은 변경하지 않았다. 새 전역 단축키와 자동 해설 기본값 변경은 후속 과제로 남겼다. 기존 첫 안내 확인 기록도 초기화하지 않았다.

새 안내·상태·실습·기본 조작의 **생성 요청 0회**는 설치 확장 검사로 확인했다. 같은 진행 질문 두 번은 모의 HTTP 응답 경계에서 요청 **1회**로 합쳐졌다. 이 결과는 실제 모델 토큰 수나 동일 조건 전후 절감률을 뜻하지 않는다.

계측은 기존 요청별 단계·모델·성공/시도·재시도·입력/출력/추론/캐시/총토큰 기록을 유지한다. 사용량이 없는 요청은 `미측정`이며, 영상·자막·질문·키를 측정 로그에 남기지 않는다. [이번 dry-run 결과](token-dry-run.json)는 `provider_configured=false`, `eligible_for_submission=false`, `reduction_percent=null`이다.

```bash
.venv/bin/python scripts/measure_gemini_tokens.py \
  --manifest scripts/fixtures/gemini-token-benchmark.example.json \
  --output /private/tmp/sullivan-token-dry-run.json
```

실측은 [기존 재현 절차](../../GEMINI_TOKEN_OPTIMIZATION_2026-11-16.md)의 비공개 manifest, 같은 영상·모델·질문·시각·문제 모드, 균형 AB/BA, 재시도 포함 총량과 사람의 품질 검토를 따른다. 실제 자료·공급자·비용 범위를 준비한 뒤 명시적인 live 옵션으로 별도 실행한다. 키나 비공개 자료를 커밋하지 않는다.

## 품질 비교와 기본값 결정

작은 `<`/`≤` 변경, 축·단위, 긴 지문·밑줄, 이미 읽은 판서, 흐린 화면, 화면 정답, 후반부/여러 시점 질문의 **결정적 회귀와 모의 공급자 경계**는 통과했다. 누락·시각 불일치·숫자/부호/단위 변경·확신도 0.72 미만의 보류와 관련 설명 제거도 검사한다. 이 결과를 실제 모델 판독·답변 품질 동등성으로 간주하지 않는다.

제출 기준 중 **실제 모델 품질 무퇴보와 재시도 포함 실측 총토큰 감소가 아직 확인되지 않았다.** 따라서 제출본은 계속 **`baseline`**이며 최적화 실험 경로를 기본값으로 승격하지 않았다. 외부 검증 대기 8항목과 `release_ready=false`도 유지한다.

## 남아 있는 검증과 적용

실제 Gemini 영상·질문 품질과 사용량, VoiceOver/NVDA의 실제 음성 순서·중복 낭독, 실제 마이크·브라우저 ASR, 한국어 TTS 청취, 실제 시각장애 학생·보호자 과업 평가는 남아 있다. ASR와 보류 모델 응답은 새 검사에서 명시적 대역을 사용했다. 서버 내부 판정·키보드·미디어·API/DB 실행은 실제 로컬 경로다. PostgreSQL 4개 선택형 검사, 외부 강의 사이트·권한창·코덱·외부 분석기 삭제 검증도 별도 환경이 필요하다. 알려진 로컬 회귀가 모두 통과했다는 뜻이며 모든 실환경 오류가 없다는 보장은 아니다.

현재 소스로 `dist/extensions`를 다시 만들고 서버 주소를 보존했다([빌드 대조](local-build.json)). 사용 중인 Chrome 확장을 새로고침하고 수강 화면을 다시 열면 적용된다. 실행 중 서버·Chrome 세션과 기존 제출 ZIP은 자동 교체하지 않았다. 새 ZIP이 필요하면 현재 소스의 패키징 도구로 다시 생성해야 한다.
