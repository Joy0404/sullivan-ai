## 재발 방지

- 학생 설치 확장 검사에 재생 중 시작, 정지 실패, 대기 중 닫기, 대기 중 새 초점 보존의 **4개 회귀**를 추가했다. 기존 8개와 함께 **12개**를 검사한다.
- 패키지 검사에 현재 소스 바이트 변경·새 소스 추가·생성 확장 변경·새 확장 모듈 누락의 **4개 회귀**를 추가했다. 기존 15개를 유지해 **19개**다.
- `--inspect`의 기존 내부 무결성 검사는 유지하고 `--check-current`를 추가했다. 내부 체크섬이 정상이더라도 현재 소스나 새로 빌드한 확장과 다르면 실패한다. 현재 버전 ZIP이 존재하면 `verify_all.sh`도 이 검사를 실행한다. 검사 자체는 기존 ZIP을 덮어쓰지 않는다.

```bash
.venv/bin/python scripts/package_submission.py \
  --inspect dist/submission/sullivan-submission-0.4.9.zip --check-current
```
