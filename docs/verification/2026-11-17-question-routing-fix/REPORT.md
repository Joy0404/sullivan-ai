문장 전체가 명확한 재생·중지·10초 이동·강의 복귀 요청이면 로컬에서 처리한다. 공손한 요청과 긴급 중지, 기존 강의·버튼 선택, 준비된 화면 설명·요약·원문 읽기도 보존한다. 불분명한 조작은 임의 실행이나 모델 해석을 하지 않고 짧은 고정 안내로 다시 입력하도록 한다. 내부 소수점·부호를 지우지 않으며 `1.0초`나 `-10초`를 지원하는 10초 명령으로 바꾸지 않는다.

공유 웹 분류기·웹 학생 CSS/함수·인증·API 형식·Gemini 키와 모델 설정은 변경하지 않았다. 수정 범위는 보고된 학생 Chrome 확장의 음성·타자 공통 입력 경로다. 모든 자연어 표현을 완전히 판별한다는 뜻은 아니다.
