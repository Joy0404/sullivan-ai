## 기능·안전 확인 근거

새 두 페이지는 로그인 없이 HTTP 200으로 열리고 API나 외부 서비스에 요청하지 않는다. 가이드 문구는 현재 실제 폼과 버튼을 기준으로 작성했다. 최초 보호자 설정과 기존 계정 로그인을 구분하며 공개 회원가입을 약속하지 않는다. 샘플과 실제 분석을 구분하고, 원본의 브라우저 기본 보관·명시적 분석 동의·임시 전송과 삭제 한계를 설명한다.

영상 파일을 선택하고 이용 권한만 확인한 뒤 분석 동의 없이 제출한 경우 API 쓰기와 원본 업로드가 모두 0건이었다. 확신이 낮은 샘플 관찰의 `HOLD`, 빈 `public_description`, `safe_to_speak=false`를 확인했다. 기존 전체 회귀 테스트에서 저확신·문제 모드 정답의 API·지문·학습 안내 유출 차단을 확인했다. 새로운 안전 로직은 추가하지 않았다.

- [샘플 캡처·키보드 배정 흐름](t1-sample-flow-results.json)

JavaScript를 끈 가이드에서도 8개 단계의 본문은 모두 보인다. 개별 펼침 상태는 `aria-expanded`로 전달하고 모두 펼침·접기 결과만 짧은 polite 상태 메시지로 알린다. 캡처의 작은 글자는 이미지를 원래 크기로 열어 볼 수 있으며, 조작 설명은 이미지 밖의 본문에 있다.

## 2026-11-04 승인 후 재검증

기존 미커밋 T1 초안을 검토하고 임시 계정으로 실제 샘플 화면 12장을 다시 촬영했다. 보호자 최초 설정과 학생 생성 화면의 실제 이미지 크기에 맞춰 가이드의 `width`·`height` 두 쌍을 수정했다. 원본 영상 분석이나 공급자 호출은 하지 않았다.

- `bash scripts/verify_all.sh`: Python 48개, JSON 2개, DOM 계약 93개, 안전 9개, 재생·음성 32개, 레거시 제거 3개 정적 확인. JavaScript 구문과 모든 기존 스크립트 검사 통과. pytest `116 passed, 4 skipped, 1 warning`으로 이전 검증과 동일하다. `.venv/bin`을 PATH에 넣어 Python 3.12 환경으로 실행했다.
- 브라우저: axe 4.14.0의 소개·가이드 6개 상태에서 위반 0건. 320·390·640·1280·1920px, 200% 확대에서 가로 넘침 없음. 전체 이미지·링크 HTTP 200, 공개 페이지의 API·외부 요청 없음, 공개 페이지 JavaScript 오류 없음. 두 이미지 크기 수정 후 재검증했다.
- 키보드: 보호자 최초 설정 → 학생 생성 → 과학 샘플 열기·검토 → 배정을 실제 Tab·입력·Enter·Space로 완료했다. 단계 링크의 포커스 이동, 같은 해시로 접힌 단계 다시 열기, 역방향 Tab, JS를 끈 8단계 읽기를 확인했다.
- 영상 경계: 분석 동의 없이 영상 파일을 선택·제출했을 때 API 쓰기 0건, 원본 업로드 0건. 샘플 저확신 항목은 `HOLD`, 공개 문구 빈 문자열, 음성 출력 차단 상태였다. 문제 모드 정답의 모든 출력 경로 차단은 기존 전체 회귀 테스트로 확인했다.
- 전문 검토: ARIA·키보드·대체 텍스트/제목·대비·라이브 영역 5종을 새로 실행해 지적 0건. [재검증 원본 JSON과 런타임 근거](t1-accessibility/revalidated/), [생성된 통합 보고서](t1-accessibility-report.md).
- Hallmark: 정적 검사 0 FAIL·0 WARN. 실제 HTTP 소개 경로의 렌더 검사 0 FAIL·미해결 REFLEX 0, 경고는 지정된 9개 섹션과 푸터의 합계가 10개라는 동일 항목이다. 가이드 HTTP 경로는 안내 UI 범위에서 0 FAIL·0 WARN. 로컬 `file://` 렌더의 경로 해석 문제는 실제 HTTP 경로 검사로 구분했다. 별도 최종 검토는 `ship`, 새 지적 0건이며 [검토 기록](t1-hallmark-finish.md)을 저장했다.
- 범위: 학생 CSS·학생 함수·서버·토큰·폼 `name` 변경 없음. 기존 `index.html`에는 로그인 소개 링크 한 줄만 추가했다. 지정 레퍼런스 9개만 열어 구조를 참고했고 이미지·로고·문구를 복제하지 않았다.

실제 VoiceOver·NVDA 음성과 실제 사용자 테스트는 여전히 미확인이다. `web-design-guidelines`는 설치되어 있지 않아 실행하지 않았고, frontend-design 검토와 웹 접근성 전문 검토로 보완했다. 관련 없는 PDF와 기존 `.a11y-history/`·검증 파일은 T1 커밋에 포함하지 않는다.
