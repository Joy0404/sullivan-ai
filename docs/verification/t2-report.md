- 바꾼 파일:

## 상태와 안전 경계의 근거

학생 수·저장된 강의 수·준비 완료하며 연결 학생이 있는 강의 수로 준비 상태를 계산한다. 샘플을 미리보기만 해서는 준비 완료로 세지 않는다. 선택 설정은 저장된 값이 기본값과 같은지 비교해 ‘기본값’ 또는 ‘완료’로 표시하며 저장 시각을 만들어 내지 않는다. 진도·메모 수 조회는 T5 범위이므로 추가하지 않았다.

분석 동의 없이 영상 파일을 선택·제출한 경우 API 쓰기 0건, 원본 업로드 0건, 공급자 호출 0건이었다. 샘플 저확신 관찰은 `HOLD`, 공개 설명은 빈 문자열, 음성 출력 차단 상태다. 문제 모드 정답의 API·학습 안내·지문 출력 차단은 기존 전체 회귀 테스트로 확인했다. T2는 분석 후보 문구를 읽거나 안전 로직을 바꾸지 않는다.
