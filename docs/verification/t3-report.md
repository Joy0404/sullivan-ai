## 기존 동작과 안전 경계

실제 분석은 기존 `app.js` 제출 처리로 이어진다. 샘플만 기존 `openSampleSession`으로 보내며 사전 준비된 결과임을 명시한다. 영상 없이 TXT·MD·SRT·VTT·JSON만 준비하는 기존 경로도 유지했다. 임시 계정으로 올린 TXT의 고유 문장이 실제 반환 지문에 포함됨을 확인했다.

샘플로 바꾸면 호환되지 않는 선택 파일·링크를 비우고, 사용하지 않는 동의·권한·보호 설정 조작은 숨기고 비활성화한다. 샘플 과목은 사용자가 적은 임의 과목을 표시하지 않는다. 분석 동의를 체크하지 않은 영상은 2단계에서 멈추며 API 쓰기·원본 업로드는 0건이었다. 실제 분석의 설정·동의·체험 코드 검사와 낮은 확신/문제 정답 차단은 기존 서버·핵심 분석 코드에 남아 있다.
