## 용어와 데이터 경계

보호자 표시를 ‘핵심 개념 찾기’, ‘화면 정보 복습’, ‘해설한 이유’, ‘말하지 않고 보류한 정보’, ‘기록만 함’, ‘멈춘 뒤 설명’, ‘준비됨’, ‘체험 비밀번호 (실제 분석에만 필요)’, ‘샘플 결과 다시 불러오기’로 정리했다. 보호자 이름 중복은 T2 처리를 유지한다. `INTERRUPT`도 ‘잠깐 멈춰 설명’으로 표시한다.

내부 코드·CSS 상태 클래스·분석 JSON은 바꾸지 않는다. 실제 브라우저에서 화면 전환 전후 snapshot JSON이 정확히 같음을 확인했다. 학생 이름은 표시 변환에서 제외하고, 학생 역할로 전환할 때는 원래 공유 UI 문구와 ARIA 이름을 복원한다. 전환 직전에 새로 작성된 학생 문구는 덮어쓰지 않는다. 요약은 안전 해설 합계·보류 수·개념 수만 읽으며, 전문 검증용 후보 문구 getter 호출은 0회였다. 안전 판단·TTS 필터와 시각·이유는 기존 코드를 그대로 사용한다.

Hallmark 렌더는 인증 후 DOM의 읽기 전용 사본과 최종 CSS를 사용한다. 이 사본에는 외부 iframe의 포커스 동작을 재현하기 위해 앱의 DOM 포커스 처리만 그대로 포함하며, 인증·분석·공급자 스크립트는 포함하지 않는다. 실제 앱의 프레임 키보드 진입 검증은 별도다. 기존 흰색 토큰·큰 저시력 조작·네이티브 legend의 테두리 위치는 근거를 적어 예외 처리하고, 기존 학생·로그인 컨테이너 F7은 범위 밖으로 기록했다.
